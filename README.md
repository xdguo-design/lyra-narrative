# NarrativeOS

AI-native storytelling operating system.

## Vision

NarrativeOS is a production workflow platform for long-form fiction creation.

It separates:

- AI writing agents
- review agents
- skill memory
- world building
- character consistency
- version management

## Core Workflow

```
Creative Task
    ↓
Writer Agent
    ↓
Reviewer Agents
    ↓
Revision Agent
    ↓
Final Version
    ↓
Skill Update
```

## Modules

- Agent Workflow
- Skill Library
- Character Engine
- World Engine
- Review Pipeline
- Version System

## First Test Project

Slow World (`slow-world-novel`)

A post-apocalyptic time ability novel used to validate the complete AI writing workflow.
