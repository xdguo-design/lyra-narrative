# 第一卷 1—30 章总纲 v1

状态：FROZEN v1  
原则：章节标题可微调，**章节功能、主要状态变化、伏笔接口和阶段结局不可随意漂移**。

## 一、第一卷总目标
陈安从“出了事先挨板子的白役”，走到“皂班愿意长期调用、出现正式差役入口的人”。

第一卷必须同时推进：
1. 失粮 / 马二主案；
2. 债务与家庭；
3. 周虎对陈安的使用信用；
4. 陈安 / 赵六搭档形成；
5. 熟练度从一次性惊喜变成长期成长规则；
6. 县衙与县城利益网络第一次露出轮廓。

## 二、作者端真相｜马二 / 失粮线
此段仅供 Writer / Reviewer，不允许正文提前泄露。

- 孙成长期利用“破袋、临时移放、补录”等程序灰区，把少量粮食从正常入库链条中挪出去。
- 昌丰粮行愿意低价接这种来源模糊的粮；郑福负责过实际搬运与接头。
- 刘旺只完成了一次被孙成指使的搬运，拿了五文钱，不是主谋。
- 第二章发现的粮袋实际短三斗一升；其中至少三斗属于人为分取。剩余一升是否来自破袋撒漏，第一卷不要求强行证明。
- 马二作为运粮车夫，逐渐发现“车上实际情况”和回票 / 入库说法有出入。他没有立即报官，而是想拿这个把柄换钱。
- 马二进入东街二巷，是去找与昌丰粮行有关的人谈价。
- 郑福与马二在有遮蔽的后屋发生冲突，马二受致命伤。死亡不是预谋杀局，但事后移尸、掩盖是主动选择。
- 尸体在雨后被移到巷中，因此“环境湿、鞋底却不符合自行走入”的异常成立。
- 孙成参与粮食流转造假，但不得被写成马二之死的全知主谋。
- 梁掌柜知道粮行吃过来源不清的便宜粮，但第一卷证据不足以把所有责任都压到他身上。
- 第一卷结案应留下“这类灰色流转不只一处”的制度性余味，为 31—100 章埋接口。

## 三、1—10 章
以现有 `chapters-01-10-plan.md` 为准，冻结不变。
关键状态：
- 3：陈安第一次被周虎主动留下。
- 6：家庭与债务进入可执行数字；陈安开始主动找付钱的活。
- 9：赵六第一次在关键时刻主动承担一点风险。
- 10：陈安 / 赵六第一次以“一组人”完成夜差，并得到 12 文。

## 四、11—15｜钱、信用、身份门槛
### 11《十二文》
主要发动机：家庭 / 钱。  
功能：
- 12 文真正进入家庭分配，不做爽点数字。
- 药、米、还债不能同时满足。
- 小满要求参与决定，陈安不能继续替全家单方面安排。
变化：家庭从“哥哥负责”进一步变成“钱必须一起算”。

### 12《保结》
主要发动机：身份。  
功能：
- 建立本书 canon：正式差役入口除了能力，还需要空缺、籍册 / 保结等程序条件。
- 周虎明确：能干活，不等于马上能进名册。
- 陈安第一次正面看到“身份门槛不是技能条”。

### 13《先还二十文》【小高潮】
主要发动机：债务。  
功能：
- 刘三爷只认兑现，不认漂亮话。
- 陈安拿出一笔真实小额还款，并拿出稳定差事来源解释后续。
- 换到有限宽限，不是免债。
变化：
- 刘三爷对陈安从“烂账”变成“仍需观察但开始有回收可能”。
- 小满看到哥哥第一次用兑现而不是承诺解决问题。

### 14《旧回票》
主要发动机：工作 / 调查。  
功能：
- 陈安在一项正常差事中再次碰到马二运输链的旧回票。
- 异常不是“自动送上门”，而是他因工作接触到大量普通票据后才注意到一个数字 / 签押不一致。
- 伏笔：异常可能不只一次。

### 15《两本账》
主要发动机：程序冲突。  
功能：
- 孙成用“补录 / 临时转放 / 旧例”争解释权。
- 陈安没有资格拿走原账，只能在周虎允许范围内抄录 / 对照。
- 文书能力开始真实训练，但不立刻弹新技能。
变化：陈安第一次意识到“查得出”之外，还要“拿得住程序”。

## 五、16—20｜县城开始认识这个白役
### 16《这活给你》【小高潮】
主要发动机：工作。  
功能：
- 周虎把一件与主案无关、但有时限和责任的付钱差事单独交给陈安。
- 陈安完成，不靠破案。
- 第一次真正得到“以后这种活可以先叫他”的使用信用。
熟练度：满足条件时可首次出现【差务·初学】，但不得与第 1 章一样做成大弹窗。

### 17《人跑了》
主要发动机：差务 / 县城生活。  
功能：
- 一名需要找到的普通脚夫 / 欠工对象提前离开。
- 陈安第一次在县城追人失败。
- 途中自然接触昌丰粮行与郑福，但此时郑福只是当地脚夫头，不标红。

### 18《再走一遍》
主要发动机：训练。  
功能：
- 陈安复盘失败路线，利用真正的道路、铺户营业时间、脚夫习惯重新找人。
- 不允许“灵光一闪直接找到”。
- 赵六提供县城人情和旧经验，不能只有陈安一个人聪明。

### 19《青石桥下》【小高潮】
主要发动机：行动。  
功能：
- 陈安靠修正后的方法找到目标并完成差事。
- 【寻迹】可以获得一次显著进度，但是否升“入门”由实际累计决定，不按计划强升。
变化：
- 县城部分脚夫 / 铺户开始知道“皂班那个年轻白役办事还算靠谱”。
- 赵六与陈安的搭档关系从县衙内部扩展到县城跑动。

### 20《昌丰粮行》
主要发动机：人情 / 调查。  
功能：
- 通过正常差事 / 路线关系确认东街二巷与昌丰粮行后门体系存在空间联系。
- 只能形成“值得查”的关联，不能直接定性粮行涉案。
- 郑福第二次出现时，读者应认得这个人，而不是突然冒出新凶手。

## 六、21—25｜能力越有用，错误也开始有代价
### 21《马二想卖什么》
主要发动机：调查。  
功能：
- 证词确认马二生前确实想拿“知道的事”换钱。
- 不知道他到底掌握多少，也不知道他向谁开价。
- “想换钱”不能自动推成“因此被杀”。

### 22《旧账不止一页》【小高潮】
主要发动机：文书 / 调查。  
功能：
- 多次抄录与对照后，发现类似“破袋临时移放 / 后补记录”的异常不止一页。
- 这把问题从“昨晚一个袋子”升级为“可能存在重复做法”。
- 孙成仍有程序反击空间。
熟练度：若前面真实训练充分，可出现【文书·初学】；不得凭看一眼账册获得。

### 23《药晚了一锅》
主要发动机：家庭。  
功能：
- 陈安因差事 / 隐瞒安排导致家里一次真实生活后果：药、饭、约定或小满自己的工钱安排被耽误。
- 小满的冲突必须针对“你又替我决定”，不是无理取闹。
变化：陈安的“我自己扛”第一次明确伤到关系。

### 24《不能只盯孙成》
主要发动机：调查 / 选择。  
功能：
- 新证据把粮食的物理流转指向县衙之外。
- 周虎要求陈安只做观察 / 跑腿，不得擅自扣人。
- 陈安形成一个未确认判断，选择多看一步再报。

### 25《人没等到》【小高潮】
主要发动机：代价。  
功能：
- 因陈安想再确认一步，一个可用中间人 / 关键接头对象提前离开。
- 不是为了惩罚谨慎，而是告诉他“谨慎也有时效成本”。
- 周虎明确指出问题在“该报的时候没报”，不是“你为什么没抓人”。
变化：
- 陈安第一次为自己的判断节奏承担职业后果。
- 周虎信任不归零，但开始对他提出更高要求。

## 七、26—30｜第一阶段收束
### 26《东街二巷后门》
主要发动机：调查。  
功能：
- 补足马二最后路线。
- 证据支持：马二在死亡前进入过昌丰粮行后部可遮雨区域。
- 与干燥鞋底 / 移尸异常形成闭环，但仍不直接指定凶手。

### 27《郑福》
主要发动机：对峙。  
功能：
- 郑福的时间线与已确认路线发生冲突。
- 他有真实利益和恐惧：怕失去饭碗、怕粮行撇清、怕自己扛全责。
- 不允许一问就招；必须通过证据、关系与压力逐层压缩说法。

### 28《先保住证据》【小高潮】
主要发动机：行动。  
功能：
- 在一次取证 / 控人过程中发生混乱，郑福试图脱身或毁掉关键接口。
- 陈安的任务不是英雄追凶，而是按权限先保住一项关键证据 / 证人。
- 赵六完成主动补位，周虎负责真正控制人。
变化：陈安 / 赵六第一次在压力现场按分工办成事，而不是靠主角单挑。

### 29《孙成认的是什么》
主要发动机：结果 / 程序。  
功能：
- 证据链足以区分两件事：
  1. 孙成参与粮食流转与账目灰区；
  2. 郑福对马二死亡负直接责任并参与移尸。
- 孙成只承认可被证据压实的部分，不作全盘自白。
- 梁掌柜承认收过来源不干净的便宜粮的风险，但直接杀人责任不落到他头上。
- 留下更大问题：类似灰色粮路并非青溪县只发生这一回。

### 30《名册上还没你的名字》【阶段高潮】
主要发动机：身份 / 职业。  
功能：
- 主案形成阶段性结果。
- 债务未清，家庭裂缝未清，县衙内部也没有“全员认可”。
- 周虎告诉陈安：接下来确有正式差役 / 捕役的入口，但需要空缺、保结、试用 / 考察等条件。
- 陈安获得的是“进入通道”，不是当场升职。
阶段变化：
- 陈安：可替代白役 → 有明确职业上升入口。
- 赵六：滑头同伴 → 能执行关键配合的固定搭档。
- 周虎：临时使用 → 愿意为二人争取持续差事和考察机会。
- 家庭：开始共同算钱，但“陈安替别人决定”的问题仍在。
- 对立面：从孙成 / 郑福个人，升级为“程序 + 粮路 + 县城利益网络”。

## 八、31—100 长线方向
### 31—45｜试用与县城差务
- 陈安争取正式差役入口。
- 处理追人、赌坊外围、债务执行、日常纠纷等，不让案件全是命案。
- 刀棒 / 擒拿开始真实训练。
- 赵六的经验开始成为陈安不可替代的补充。

### 46—60｜乡里冲突
- 乡村械斗、失踪、土地 / 水路争执等把“县城经验”推到陌生环境。
- 寻迹与身体技能经历失败 → 调整 → 提升。
- 陈安第一次发现“查明白”与“处理得下去”不是一回事。

### 61—80｜粮税与旧网络
- 第一卷留下的灰色粮路重新出现，但不是简单复活旧反派。
- 对手从某个坏人升级为书吏、粮行、里正、承运人彼此利用的利益链。
- 文书 / 核账能力变得重要。

### 81—100｜县里有名
- 陈安形成稳定同伴与外部信用。
- 获得正式身份后，第一次因为自己的判断让别人承担明显代价。
- 阶段结尾：成为县里“遇到棘手差事会想到的人”，但进入更高层利益视野。
