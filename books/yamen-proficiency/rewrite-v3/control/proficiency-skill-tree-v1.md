# Proficiency Skill Tree v1｜熟练度发展树

状态：FROZEN v1

## 1. 总原则
- 系统只记录“真实做过 + 有反馈 + 形成有效学习”的技能。
- 系统无人格、无任务、无商城、无抽奖、无奖励包。
- 系统不能指出线索、判断谎言、生成未知知识、赋予社会身份。
- 无意义重复收益快速衰减。
- 身体、知识、权限、人情都是硬上限。
- 技能等级：初学 → 入门 → 熟练 → 精通 → 大成；每阶段内部 0/100。
- 前 100 章禁止轻易出现“精通 / 大成”。成长要有失败、调整与重复实践。

## 2. 技能族

### SK-01 寻迹
含义：从足迹、拖痕、车辙、遗留物、路线连续性中形成稳定观察和复核习惯。  
不能做：自动告诉“这是谁留下的”“这是不是凶手”。  
首次：第 1 章真实寻迹后出现【寻迹·初学】。  
1—30：
- 经历县衙现场 + 县城追人失败 / 复盘；
- 可显著提升，但是否在第 19 章升“入门”取决于正文累计，不强制。
31—100：
- 在乡间、雨地、多人混杂现场继续训练；
- 目标上限：稳定进入“熟练”前后，不冲“大成”。

### SK-02 差务
含义：跑差、守门、交接、控制物品、执行命令、时间判断、知道何时汇报。  
不能做：赋予正式权限。  
首次候选：16 章，在连续完成真实差事后才记录。  
核心作用：让“可靠”有可学习的行为基础，但周虎是否信任仍由现实结果决定。

### SK-03 文书
含义：抄录、核对常见县衙文书、理解字段、签押和常用流程。  
前置 canon：
- 原主具备最基础识字能力：常用姓名、数字、日期、简单衙门用字能认；
- 复杂文书、账册规则和程序含义需要重新学习。
首次候选：22 章前后，在多次真实抄录 / 对照后。  
不能做：看一眼复杂账册就懂全部规则。

### SK-04 核账
含义：对数字、单位、前后记录、合计与流转关系进行复核。  
前置：文书基础 + 多次真实账务比较。  
建议出现：61—80 阶段。  
不能做：自动识别假账；只能提高发现不一致的能力。

### SK-05 识人
含义：积累对说话节奏、回避方式、利益位置、关系反应的经验。  
建议出现：31—60 以后。  
不能做：
- 鉴谎；
- 读取情绪数值；
- 通过眼神直接知道真相。
通过条件：必须经历“判断错人 / 低估人”的反例训练。

### SK-06 刀棒
含义：基础冷兵器动作、距离、发力、守势。  
建议出现：31—45 正式差务训练期。  
身体限制：受伤、饥饿、疲劳直接影响发挥。  
不能做：短期内打赢多年练家子。

### SK-07 擒拿
含义：控制、脱身、协同拿人。  
建议出现：31—60。  
前置：真实训练 + 实际控制人经验。  
核心：更多服务“安全控制”而非武侠打斗。

### SK-08 验伤
含义：在仵作 / 老差役指导下学习观察外伤、伤势描述、搬动禁忌。  
建议出现：46—100。  
不能做：
- 取代仵作；
- 现代法医推理；
- 仅凭一眼精确判断死亡时间和凶器。

## 3. 1—30 章可见技能预算
- 必须有：寻迹。
- 最多新增两个明确显示技能：优先差务、文书。
- 刀棒 / 擒拿 / 验伤 / 识人可以出现训练前置，但不要急着弹面板。
- 禁止每章至少一个技能点的“打卡式升级”。

## 4. 31—100 发展原则
- 每次技能明显提升前，至少出现：真实任务 → 阻力或失败 → 调整 → 再完成。
- 不同技能允许组合，但组合结论仍由陈安自己得出。
- 技能越多，正文越要减少面板频率；熟练度存在感通过“以前做不到、现在稳定做得到”体现。

## 5. 长期上限
100 章前：
- 陈安可以成为县级差务中很能干的人；
- 不能成为全能神探、顶级武人、神医、账房大师。
100 章后：
- 身份和见识扩展后才有资格继续提升上限。
