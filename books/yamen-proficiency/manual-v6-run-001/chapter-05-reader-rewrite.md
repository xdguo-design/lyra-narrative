# 第五章 Reader Gate · Rewrite 1

陈安进门时，陈小满正坐在桌边分铜钱。

七枚钱分成三堆，她捏着最后两枚，还没想好往哪边放。听见门响，她也只是抬了下眼。

陈安先看见锅里的稀粥，随后才注意到米缸没盖严，缸底已经露出来。墙角还放着三包药，其中一包拆了线。

“刘三爷的人又来过没有？”

“没有。”小满问，“你回来就问这个？”

陈安伸手去碰桌上的钱，她先按住中间两枚。

“这个买药。”

“药还有三帖。”

“那是今早以前剩的。”

陈安把手停在桌边，转而问米还能吃几天。

“省着吃，三天。”

窗边的柳氏一直在理线，这时才问：“吃饭没有？”

“吃过了。”

小满朝灶台那边看了一眼。锅里的粥一点没少。

“县衙现在还管白役午饭？”

陈安没接这句，只说粮找到了。

“粮找到了，你还回县衙干什么？”

“那边还有事，我一会儿得回去。”

“那你刚才还说跟家里没关系。”

陈安把那两枚药钱重新拨回中间。

“小满，这两天别去县衙。刘三爷的人再来，也别跟他们顶。门关上，等我回来。”

小满没有应。她用指尖把那两枚钱慢慢推回饭钱那边。

“既然不关家里的事，为什么还不让我去？”

“就是因为还有事。”

“会落到你头上？”

陈安的手还搭在桌沿上。小满没再追，只把两堆钱重新并到一起。

“三天饭，两天药。你先选一个。”

“药不能停。”

“那钱从哪儿来？”

“我会想——”

后半句没出来。

小满这才抬头。

“你以前也是这么说。”

陈安把手从桌边收了回来。那几枚钱就在两人中间，他没有再碰。

“钱现在没有。”

小满的手指仍压在最上面那一枚。

“县衙的事也还没结束，我今天得回去。”

“会不会牵到你？”

陈安低头看了一眼桌上的钱。

“现在还不知道。”

窗边传来细细一声响。柳氏手里的线断了，她把针搁到腿上，说：“药只剩两帖半。”

陈安转头。

“不是还有三帖？”

“早上那帖，我喝了半碗。”

“为什么？”

“先省着。”

小满嘴唇动了一下。

柳氏看她一眼：“别替我圆。”

她伸手把两枚铜钱从一堆里拣出来，放回中间，剩下五枚推到小满面前。

“这两枚买药。米只够三天。”

陈安问：“债呢？”

柳氏低头把断线重新穿进针眼。

“这七文先别算债。”

针尖穿过去，她把线拉直。

“明早还得买米。”
