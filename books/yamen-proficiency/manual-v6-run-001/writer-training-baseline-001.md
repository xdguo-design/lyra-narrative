# Writer Training Baseline 001

WRITER_TRAINING_DIAGNOSIS_V1

作品：《穿成县衙白役，我把熟练度肝满了》
样本：第一章《十五板子》至第四章《账是这么记的》
诊断范围：仅 Stage A 基线诊断
诊断维度：场景导演 / 人物行为 / 语言节奏

## 【高杠杆问题1】语言节奏过度依赖短句、单句段和“停一下再落一句”的固定拍子

【证据】
四章中反复出现相似句群：
- 第一章：“十五板子。 / 这句话把剩下的记忆也扯了出来。”
- 第一章：“母亲。 / 小满。 / 又有一些记忆对上了。”
- 第二章：“动作不大。 / 陈安看见了，赵六也看见了。”
- 第三章：“鞋底露出来。 / 前掌干。 / 后跟湿。 / 另一只也差不多。”
- 第四章：“周虎嗯了一声。 / ‘那不用站着猜。’”
同时大量段落以一两句单独断开，动作句经常使用“陈安看他 / 周虎看他 / 赵六看了一眼 / 没说话 / 没动”等相近节拍。

【影响】
单句本身多数清楚，但四章连读后会出现明显的“逐拍推进”感。阅读速度看似快，实际句群缺少长短、密疏、轻重的自然变化。尤其调查、判断、对峙一进入关键处，就习惯用短句和单独断行制造重量，容易形成新的模型腔。

【训练目标】
训练“3—5句句群节奏”：
- 先决定这一组句子的功能是进入、承接、加压、停顿还是落点；
- 只在真正需要冲击时使用单句段；
- 减少“看了看 / 没说话 / 停了一下”作为默认节奏器；
- 允许完整长句承担连续动作和观察；
- 关键处不是靠断句变重，而是靠信息、动作和人物关系本身变重。

## 【高杠杆问题2】场景推进过度依赖“查线索—验证—再得一个新问题”的调查循环

【证据】
第一章：米粒 → 蓝麻线 → 车辙 → 缺角鞋印 → 刘旺。
第二章：车与鞋印 → 刘旺逐层承认 → 柴房 → 找回粮 → 少三斗 → 马二死亡。
第三章：尸体鞋底 → 石灰 → 巷口痕迹 → 运脚回票 → 封西库、找孙成。
第四章：回票与账册 → 孙成程序解释 → 旧例缺口 → 王顺证词 → 跟踪孙成。

每章局部逻辑都成立，但四章的核心动作形态高度接近：主角观察异常，证据逐级闭合，人物被迫提供新信息，最后把问题推向下一层。

【影响】
会把“底层穿越 + 熟练度成长”逐渐写成“古代刑侦连续剧”。家庭、钱、身份羞辱、工作、人情、身体、县城生活目前更多是调味，尚未真正承担章节核心动作。长篇如果继续这样，场景再换地点，本质也仍是同一场戏。

【训练目标】
训练“场景动作形态变化”：
- 每章先定义唯一主要动作：交易、回家、求人、拒绝、吃饭、讨债、训练、犯错、等待、争抢、执行差事等；
- 主线案件允许穿过场景，但不能每次都成为场景发动机；
- 场景导演卡必须明确“本章不靠什么推进”；
- 每章至少有一个只能由生活/身份/关系产生、不能被线索替代的核心变化。

## 【高杠杆问题3】人物行为已经开始分化，但陈安的“正确行为”过多，人物缺点尚未真正制造代价

【证据】
陈安目前连续表现为：
- 第一章：发现线索但不过度判断；
- 第二章：“粮呢？不知道。谁拿的？不知道。”严格限定证据；
- 第三章：“只能说这双鞋不像从湿地上走了五六步。”拒绝越界判断；
- 第四章：“我不懂账，就是觉得绕远了。”只抓物理矛盾，不抢程序判断。

这些行为都合理，也符合人物卡中的谨慎、观察力强。但人物卡同时写有：前期过于现实、能躲麻烦就躲、容易把关系当成本收益来算。目前这部分几乎没有真正让他做错选择、错过东西、得罪人或付出关系代价。

刘旺和孙成的受压反应已经明显区分：刘旺是缩、逐层松口；孙成是抢解释权、拿程序保护自己。这说明“人物卡约束对白”开始成立。但主角仍主要以优点推进剧情。

【影响】
如果主角每次都谨慎、正确、边界清楚，他会越来越像“作者最可靠的推理工具”，而不是一个会因为性格付代价的人。长篇爽感会有，但人物成长空间会被提前吃掉。

【训练目标】
训练“缺点进入行动”：
- 每个重要场景不只问“陈安会正确地做什么”，还要问“他的现实、算账、避险会让他本能地回避什么”；
- 至少允许一次判断正确但关系处理错误，或利益计算正确但长期代价更大；
- 不为了制造瑕疵强行降智，错误必须来自人物卡中已经存在的性格；
- Coach 要检查人物缺点有没有改变选择，而不是只存在于设定文档。

【场景导演】EMERGING
说明：单场空间、目标、证据链已经清楚，第四章也开始出现权力关系变化；但连续章节的主要动作形态重复，场景选择仍主要服务调查推进，尚未稳定形成长篇层次。

【人物行为】EMERGING
说明：刘旺、周虎、孙成已经有明显不同的受压方式，人物卡开始真正约束对白；但主角的缺点还没有进入关键选择，次要人物也仍有被功能化使用的风险。

【语言节奏】NEEDS_WORK
说明：自然中文与可读性总体成立，但四章范围内短句、单句段、停顿式动作句的复用频率过高，已经形成稳定习惯，属于需要专项训练而非局部润色的问题。

## 本轮最高优先级训练目标

1. **句群节奏训练**
   从“逐句都清楚”提升到“3—5句形成自然呼吸”，重点戒掉单句段、动作停顿和短句连续作为默认强调手段。

2. **场景动作形态训练**
   强制把调查之外的生活、债务、身份、家庭、工作、人情变成真正的场景发动机，避免每章都靠发现新线索推进。

3. **人物缺点进入选择训练**
   让陈安的现实、避险、算账真正产生一次可追踪的关系代价或错误选择，使人物成长建立在性格矛盾上，而不是只靠能力增长。

## 诊断边界

- 本轮没有修改正文。
- 本轮没有提供范文。
- 本轮没有把单句问题当作孤立文病处理。
- 三项训练目标均来自四章范围内的重复模式。
- 尚未进行 Scene Direction Card、Behavior Matrix、语言节奏重写或迁移测试，因此本轮不授予 TRANSFERABLE。
