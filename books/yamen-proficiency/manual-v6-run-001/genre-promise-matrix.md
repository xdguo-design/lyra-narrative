# Genre Promise Matrix v1

作品：《穿成县衙白役，我把熟练度肝满了》

## 核心定位

本书不是“古代刑侦 + 熟练度皮肤”。

核心阅读承诺是：

1. **底层县衙生存**
   - 白役没有稳定身份、收入和保护。
   - 脏活、责任、处罚、差饭、脚钱、排班都必须持续影响选择。

2. **钱 / 债 / 家庭**
   - 一贯二百钱不是背景数字。
   - 柳氏的药、米、小满的劳动与陈安的收入必须持续形成具体选择。
   - 家庭不是主角下班后的温情插曲，而是现实成本中心与关系线。

3. **熟练度真实成长**
   - 技能只来自真实行动、练习和反馈。
   - 熟练度给“今天学会的明天不会白费”，不给答案、资源、身份和别人信任。
   - 面板出现频率服从成长事件，不按章打卡。

4. **身份 / 职业晋升**
   - 从白役到“别人愿意把活交给他”，再到正式差役，是第一卷主要爽线。
   - 晋升必须由可靠性、技能、关系、责任与机会共同构成。
   - 不能靠破一个案子直接跳级。

5. **县城生活与社会层级**
   - 粮行、布庄、脚夫、债主、库吏、白役、皂役、班头、铺户和普通百姓共同构成青溪县。
   - 不同身份拥有不同说话权、风险和解决问题方式。
   - 县城必须像有人生活，不是只为案件搭出来的地图。

6. **案件与危险**
   - 案件用于制造风险、能力转换和制度摩擦。
   - 案件不是每章唯一推进器。
   - 调查必须与生存、钱、身份、人情至少一项发生交叉。

# 第一阶段 1—30 章 Promise Distribution

## Block A｜1—5 章：挨打之后先活下来

### 必须兑现
- 底层县衙生存：HIGH
- 钱 / 债 / 家庭：MEDIUM → HIGH
- 熟练度成长：MEDIUM
- 身份 / 职业：LOW → MEDIUM
- 县城生活：MEDIUM
- 案件 / 危险：HIGH

### 结构要求
1—4 章可以由失粮 / 马二线占较高比重，但第 5 章必须明显切回家庭、生计或债务。

### 必须影响选择的非调查承诺
至少 3 项：
- 板伤影响行动；
- 家庭缺米 / 药影响是否接活；
- 债务期限影响挣钱选择；
- 白役身份限制陈安能问什么、碰什么。

### 禁止
- 连续五章都是“找异常 → 问人 → 新线索”。
- 系统替陈安确认谁说谎。
- 周虎因为陈安聪明就直接特殊提拔。

## Block B｜6—10 章：能力开始值钱，但还换不来身份

### 必须兑现
- 底层县衙生存：HIGH
- 钱 / 债 / 家庭：HIGH
- 熟练度成长：MEDIUM
- 身份 / 职业：MEDIUM
- 县城生活：HIGH
- 案件 / 危险：MEDIUM

### 章节发动机建议分布
- 1 章：挣钱 / 临时差事
- 1 章：家庭后果
- 1—2 章：主案推进
- 1 章：县衙工作 / 人情

### 关键效果
陈安第一次发现：
“会做事”不等于“有身份”。

他可以比正式差役更有用，但：
- 钱未必更多；
- 锅仍可能先落在白役身上；
- 说话权仍有限。

### 必须出现
一次“能力有用但没有即时奖励”的事件。

---

## Block C｜11—15 章：债务与身份第一次正面碰撞

### 必须兑现
- 钱 / 债 / 家庭：HIGH
- 身份 / 职业：HIGH
- 县城社会层级：HIGH
- 熟练度：MEDIUM
- 案件：LOW → MEDIUM
- 危险：MEDIUM

### 核心问题
陈安需要更稳定的钱，但更稳定的钱依赖更稳定的身份。

刘三爷的作用：
- 不是阶段 Boss；
- 是信用压力；
- 逼陈安把“我有办法”变成可兑现的收入与期限。

### 家庭要求
小满不能一直只是等哥哥挣钱。
她自己的劳动选择必须至少一次改变家庭决策，并与陈安的控制倾向冲突。

### 禁止
用破案奖金一次性清债。

---

## Block D｜16—20 章：县城开始认识这个白役

### 必须兑现
- 身份 / 职业：HIGH
- 县城生活：HIGH
- 熟练度成长：HIGH
- 案件 / 危险：MEDIUM → HIGH
- 家庭 / 钱：MEDIUM
- 底层生存：MEDIUM

### 核心变化
陈安开始获得“找他办事 / 让他跟着 / 让他多看一眼”的实际信用。

注意：
这是**使用信用**，不是官职。

### 熟练度要求
至少一次技能提升必须经过：
真实任务 → 失败/阻力 → 调整 → 再完成。

不能只因为连续成功就涨点。

### 县城生活要求
至少两个非县衙人物产生持续关系：
铺户、脚夫、粮行、邻里、布庄、债务网络等。

---

## Block E｜21—25 章：能力越强，责任越重

### 必须兑现
- 案件 / 危险：HIGH
- 身份 / 职业：HIGH
- 熟练度：MEDIUM
- 家庭 / 钱：MEDIUM
- 县城层级：HIGH
- 底层生存：MEDIUM

### 核心问题
陈安不再只是“怕背锅”，开始面临：
自己判断错了，会不会让别人付代价？

### 主角缺点
现实、避险、控制必须至少一次造成明显后果：
- 错过关系；
- 伤害小满信任；
- 低估某人；
- 为了稳妥失去机会；
- 为了机会牺牲生活承诺。

禁止靠降智制造失误。

---

## Block F｜26—30 章：第一阶段收束——获得位置，而不是获得人生答案

### 必须兑现
- 身份 / 职业：HIGH
- 钱 / 债 / 家庭：HIGH
- 熟练度：MEDIUM
- 县城生活：MEDIUM
- 案件 / 危险：HIGH
- 底层生存：由 HIGH 降为 MEDIUM

### 第一阶段必须完成
- 陈安不再是完全可替代白役；
- 获得正式差役 / 捕役机会或进入明确晋升通道；
- 债务从“随时压垮家庭”进入可管理状态，但不要求清零；
- 家庭关系不能因为主角有能力就自动和解；
- 熟练度证明能持续成长，但仍受身体、知识、身份限制；
- 第一阶段主案形成结果。

### 不能完成得太彻底
- 不能突然有房有钱；
- 不能县衙上下都认可；
- 不能刘三爷自动消失；
- 不能小满彻底听话；
- 不能主角变成正式神探。

# 每 5—8 章强制检查

至少 **3 个非调查型 Promise** 必须实际改变人物的选择或结果。

不算“出现”：
- 提一句没钱；
- 回家吃一顿饭；
- 面板闪一下；
- 赵六说一句笑话；
- 提到白役身份但不产生限制。

必须是“作用”：
- 因为钱少，他接了原本不想接的活；
- 因为身份低，他知道答案也没有资格直接下令；
- 因为家庭风险，他放弃或推迟一个职业机会；
- 因为技能真实提高，他完成以前做不到的动作；
- 因为县城人情，他的信息和成本发生变化。

# Chapter Promise Card

正式重写每章开写前填写：

【本章主要发动机】
只能选 1 个：
家庭 / 债务 / 工作 / 身份 / 交易 / 调查 / 行动 / 训练 / 人情 / 等待 / 其他

【主要 Promise】
1 个。

【辅助 Promise】
最多 2 个。

【本章真正改变什么】
局势 / 钱 / 关系 / 身份 / 技能 / 风险 / 信息 中至少 1 项。

【非调查 Promise 是否实际影响选择】
YES / NO

【熟练度是否出现】
若 YES，写明真实练习和反馈；若只是为了刷存在感，删除。

【与前两章发动机是否重复】
YES → 必须解释为什么不能换。
NO → PASS。

【章尾类型】
动作 / 关系变化 / 现实后果 / 发现 / 危险 / 选择
不得连续两章机械重复。

# Anti-Drift Rules

## GP001｜案件吞书
若连续 3 章主要发动机都是调查，BLOCK。

## GP002｜家庭装饰化
连续 8 章家庭只被“想起/担心/回去吃饭”提及，没有改变选择，BLOCK。

## GP003｜贫穷口号化
反复写“没钱”但没有具体支出、期限、收入方式和取舍，BLOCK。

## GP004｜身份虚化
白役身份只存在于称呼，不限制权力、收入、责任和风险，BLOCK。

## GP005｜系统打卡
连续章节为了提醒金手指存在而弹面板，LOCAL_REWRITE；形成固定模板则 REWRITE_BLOCK。

## GP006｜职业成长跳级
一次立功直接换正式身份、上级信任或稳定收入，REWRITE_BLOCK。

## GP007｜县城工具化
所有铺户、脚夫、邻居、债主都只在需要线索时出现，REWRITE_BLOCK。

## GP008｜爽点无成本
每次能力发挥都同时得到正确答案、上级认可、收入和关系改善，REWRITE_BLOCK。
