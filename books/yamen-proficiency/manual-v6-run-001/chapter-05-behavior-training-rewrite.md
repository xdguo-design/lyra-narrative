# 第五章人物行为训练片段·Rewrite 1

陈安进门时，陈小满正坐在桌边分铜钱。

一共七枚。三枚推左边，两枚放中间，剩下两枚捏在指头里。听见门响，她也没抬头。

陈安先看灶台。锅里还有半锅稀粥，米缸底只薄薄铺着一层糙米。墙角剩三包药，其中一包已经拆了线。

“刘三爷的人又来过没有？”

“没有。”小满抬眼，“你回来就问这个？”

陈安伸手去拿桌上的钱。

小满先按住中间两枚。

“这个买药。”

“药还有三帖。”

“那是今早以前剩的。”

陈安没接，转而问：“米还能吃几天？”

“省着吃，三天。”

柳氏坐在窗边理线，只问了一句：“吃饭没有？”

“吃过了。”

锅里的粥没动。

小满往灶台那边看了一眼。

“县衙今天还管白役午饭？”

陈安把手收回来。

“粮找到了。”

“粮找到了，你还回去干什么？”

“事情没收尾。”

“那你刚才说跟家里没关系。”

陈安停了一下，把那两枚药钱重新拨回中间。

“小满，这两天别去县衙。刘三爷的人再来，也别跟他们顶。门关上，等我回来。”

小满看着那两枚钱。

“你不是说事情没收尾吗？”

“所以才让你别去。”

“那到底有事没事？”

陈安没答。

小满也不催，只把中间两枚又拨进左边。

“三天饭，两天药。你先选一个。”

“药不能停。”

“那钱从哪儿来？”

“我会想——”

话到一半，陈安自己停住了。

小满终于抬头。

“你以前也是这么说。”

陈安伸出去的手没再碰那些钱。

过了会儿，他道：“钱现在没有。”

小满没说话。

“县衙那边也没完。”

她手指还按在铜钱上。

“那你刚才还说没事？”

“我没说没事。”

“差不多。”

这两个字顶得很准。

陈安没再绕。

“有点麻烦。”

小满问：“会不会落到你头上？”

陈安想了想。

“现在不知道。”

这是他今天第一次给出真正的答案。

窗边传来一声线断的轻响。

柳氏把针放下。

“药只剩两帖半。”

兄妹俩一起看过去。

她把空药碗往里挪了挪。

“早上那帖，我喝了半碗。”

陈安脸沉下来。

“为什么？”

“先省着。”

小满抿着嘴。

柳氏看她一眼。

“别替我圆。”

她从饭钱里捡出两枚，重新放回中间。

“这两枚买药。”

剩下五枚推到小满面前。

“米只够三天。”

陈安低声道：“债呢？”

柳氏重新穿针。

“七文填不了一贯二百。”

“先把明天的饭留出来。”
