# Chapters 2-3 Refinement Log

## R006 — Chapter 2 / REWRITE_BLOCK / reality
- 原问题：整袋赈粮被藏在侧门上方旧木棚，承重、搬运和搜查遗漏都勉强。
- 执行：重写为“后厨侧门旁小柴房的柴垛后方”。先由刘旺确认昨夜放粮位置，再从擦痕、未出门的米粒、外层柴垛新码痕迹推进；三人实际搬开柴后找到粮袋。
- 结果：隐藏方式可执行，也解释了早上粗搜只看通道、没有拆柴垛的原因。

## R007 — Chapter 2 / LOCAL_REWRITE / continuity
- 原问题：寻迹从1/100直接跳3/100，无收益规则依据。
- 执行：改为【寻迹·初学 2/100】。
- 结果：前期保持“一次完整有效实践，至少一次基础进度”的直觉，不建立额外倍率规则。

## R008 — Chapter 2 / POLISH / character
- 原问题：“他可能蠢”把人物贴标签，笑点略显作者推动。
- 执行：改为“真要偷一整袋粮，挑自己的车，穿自己的破鞋……省事是挺省事。”
- 结果：幽默仍在，但针对做法，不直接替陈安评价刘旺整个人。

## R009 — Chapter 3 / REWRITE_BLOCK / continuity
- 原问题：死者随身携带“按袋入仓号签”缺乏合理制度基础，是为剧情方便临时造物证。
- 执行：改为“运脚回票”：车夫送粮验收后由库吏写明袋数并盖县衙小印，车夫拿它向承运方结脚钱。
- 结果：马二随身携带合理；票上“实收十八袋 + 孙成押字”与县衙最终十七袋形成可查矛盾。

## R010 — Chapter 3 / REWRITE_BLOCK / plot
- 原问题：第二章章尾揭“马二”，第三章又准备揭“孙”，连续使用姓名揭示钩子。
- 执行：保留孙成关联，但把“孙”放在场景中段；章末落在周虎改变处置：尸体不送义庄、派人查万顺粮行、封西库、找孙成。
- 结果：钩子从“名字”变成“局势升级与立即行动”。

## R011 — Chapter 3 / DELETE instead of LOCAL_REWRITE
- 原问题：初稿又显示【寻迹 5/100】，形成“每章必须亮面板”的机械节奏。
- 执行：整段面板显示删除。第三章允许技能在后台积累，但不强制每章播报数值；下次真正需要显示时再让陈安看到。
- 结果：金手指存在但不抢剧情。
