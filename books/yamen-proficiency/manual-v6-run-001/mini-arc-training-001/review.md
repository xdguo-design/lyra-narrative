# Three-Chapter Mini-Arc Review

## 模拟章节
1. 《三天》——家庭 / 债务谈判
2. 《六文工钱》——县衙工作 / 身份
3. 《别往人多的地方追》——调查 / 行动

全部为训练模拟，不进入正史。

## 连续性检查

### 1. 开场机制
- Ch1：债主进入家庭院落。
- Ch2：县衙后院出现成排湿木箱。
- Ch3：前院突然有人冲出，直接进入追逐。

结果：PASS
没有连续使用“醒来 / 发现异常 / 被叫过去”。

### 2. 主要发动机
- Ch1：谈判——如何用有限信用换三天。
- Ch2：劳动/工作——如何把脏活转成可被记住的可靠性。
- Ch3：行动——在人群和空间中追人。

结果：PASS
未形成“线索 → 验证 → 新线索”三连。

### 3. 幽默来源
- Ch1：几乎无笑点，压力靠账和家庭。
- Ch2：赵六对“纸也挺亲”、借六文的即时避险。
- Ch3：赵六把追人也先换算成工钱。

风险：
赵六仍然容易把“怕亏”变成固定笑点。

处置：
记为 LONG001 / WATCH，不 blocking。
正式重写中不能每次赵六出现都谈钱。

### 4. 章尾类型
- Ch1：火快灭了——生活画面。
- Ch2：离十五文还差九文——现实目标推进。
- Ch3：追人成功但仍差九文——行动结果重新撞回生存目标。

风险：
Ch2 / Ch3 连续都以“差九文”落点，形成重复收束。

判定：
LONG002 / LOCAL_REWRITE

修改建议：
Ch2 保留“还差九文”作为目标；
Ch3 不再重复数字，改落在“追人没有额外钱，现实缺口未因能力表现自动消失”的具体动作，不再直接复述九文。

### 5. 家庭 / 经济 / 身份 / 案件比例
- Ch1：家庭、债务、信用主导。
- Ch2：工作、收入、身份主导。
- Ch3：动作、寻迹主导，但钱仍作为背景代价。

结果：PASS
案件/追踪没有吞掉三章。

### 6. 陈安缺点是否产生代价
- Ch1：先承诺后找钱，把自己锁进明确期限。
- Ch2：主动接更多责任，但收入不增加。
- Ch3：选择抄近路是有限判断，不保证正确；身体伤势仍制约动作。

结果：PASS
未出现“每次正确且没有代价”。

### 7. 熟练度
仅 Ch3 出现。
出现条件：
- 先观察泥迹；
- 实际选择路线；
- 完成追踪并抓到人；
- 系统只记录已经完成的寻迹。

结果：PASS
未触发 F015。

## LONG002 修订

原 Ch3 末尾：
“明晚以前，还差九文。”

建议替换为：
赵六还坐在泥里算今天这趟值多少钱，陈安没有接。他把衣里的六枚铜钱按回去，跟着周虎往县衙走。

效果：
- 不重复 Ch2 的数字钩子；
- 仍保留债务压力；
- 结束于行动，不总结主题。
