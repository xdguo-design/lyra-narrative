## Remaining Watch Items
1. LONG001：赵六“怕亏/算钱”不能变成固定笑点。
2. 正式正文中刘三爷首次出场仍需 Character + Reader 复核。
3. 孙成第三类压力出现时再确认 TRANSFERABLE。
4. 连续 5—8 章仍必须使用 Genre Promise Matrix 防漂移。

## Production Activation Rules
1. 每章一个主要发动机。
2. 连续三章调查发动机 = BLOCK。
3. 陈安能力发挥必须检查真实成本。
4. 读者可不知道答案，但必须知道未知项。
5. 高压动作优先保证空间和动作对象清楚，不用碎句假装紧张。
6. 至少一名关键人物保持自身利益边界。
7. 熟练度只在真实行动 + 反馈后出现。
8. 章尾类型连续重复时，优先重写后章。
9. 每 5—8 章至少 3 个非调查 Promise 真正改变选择。
