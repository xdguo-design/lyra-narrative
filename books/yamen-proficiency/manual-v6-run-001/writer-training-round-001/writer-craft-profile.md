# Writer Craft Profile

WRITER_CRAFT_PROFILE_V1

【稳定能力 STABLE】
- 语言节奏：能根据场景压力调整句群长短；家庭场景与上下级工作场景中均未复发连续碎短句、单句段堆叠和“看了看/没说话/停了一下”默认节奏器。
- Reader 语义边界：能在保留悬念时补足一次阅读所需的对象与行动支点；已能区分“答案未知”与“未知项本身不明确”。
- 人物声音基础分化：陈安、陈小满、柳氏、赵六、周虎在训练场景中说话与受压行为可区分。

【不稳定能力 EMERGING】
- 高压动作/危险场景中的语言节奏尚未专项迁移验证。
- 连续多章层面的节奏与动作形态变化尚未通过三章 mini-arc 测试。
- 编辑介入后的声音保护尚未验证；当前结论只针对 Writer 原始输出。

【待训练 NEEDS_WORK】
- 无当前单场写作维度 NEEDS_WORK。
- 长篇连续性与 Editor deliberate practice 尚属于前置未完成项目，不计入本轮 Writer 单场维度。

【可迁移 TRANSFERABLE】
- 场景导演：能够从调查场景迁移到家庭经济场景与上下级工作场景，并主动改变主要动作形态，不依赖新线索维持推进。
- 人物行为：能够让同一人物的既定缺点在不同压力下产生不同具体行为；陈安的现实/控制倾向已在家庭关系与职业选择中产生真实代价，而不是只表现为“谨慎正确”。
- 信息攻防：人物不再因为剧情需要自动合作；小满、赵六、周虎均保持自己的利益位置与让步边界。

【高频失败模式】
- 为了克制或留白删除必要语义支点，形成“县衙那边也没完”式模糊。
- 连续章节容易退化为“发现线索 → 验证 → 再得到一个问题”。
- 陈安容易连续做出边界清楚、判断正确、代价很小的选择，变成作者工具。
- 关键处容易用短句、单句段和通用停顿动作制造假重量。
- 章尾有用总结句替读者点题的历史风险。

【下一轮训练】
1. 高压动作场景节奏迁移：在追逐、意外、身体危险或多人混乱中保持空间清楚、句群自然，不退化为碎短句。
2. 三章 mini-arc 连续写作：家庭/经济 → 工作/身份 → 调查/行动三种发动机连续运行，检查动作形态、笑点、章尾、人物缺点和类型承诺是否重复。

【正式写作激活规则】
1. 每章先写唯一主要动作；若连续两章都能概括为“查线索”，立即换发动机。
2. 陈安每个重要选择都检查：他的现实、避险、算账是否真的产生了代价。
3. 读者可以不知道答案，但必须能准确说出未知项是什么。
4. 以 3—5 句检查节奏；禁止用“看了看/没说话/停了一下”代替真实关系动作。
5. 至少一名关键人物保持自己的利益，不为推进剧情自动配合。
6. 章尾优先落在动作、关系或具体后果，不替读者总结主题。
