# 核心人物设定（行为约束版）

## 陈安
- 年龄：21
- 身份：青溪县衙白役；现代灵魂穿越。
- 外形：个子中等偏高，长期吃不好显得清瘦；眉骨偏硬，左眉尾有一道很浅的旧疤；县衙发的灰布短褂明显大了一号，袖口总往上卷。
- 神态/动作：遇事先看，不急着表态；紧张时会用拇指蹭食指指节；受伤也不爱在人前龇牙太久。
- 表层目标：先保住命、还债、让家里吃上饭。
- 深层欲望：不再做“出了事先拿来顶一下”的人。
- 优点：耐心、会观察、愿意重复练习、遇事不爱自我感动。
- 缺点：前期过于现实，能躲麻烦就躲；容易把关系也当成本收益来算。
- 幽默方式：偏冷，更多来自对自己倒霉处境的无奈和嘴上不肯认输。
- 正常说话方式：句子不长，先问事实，不急着下结论；能少说就少说。
- 语言指纹：先问事实、句子偏短，少形容词；没把握时直接说“不知道”“只能到这里”，不抢着给结论。对熟人偶尔有冷幽默，但不会为了显聪明多说。
- 非语言指纹：遇事先扫现场和人的手脚位置；紧张时拇指蹭食指指节；疼时会调整站姿或动作幅度，却不长时间在人前示弱；需要拒绝时常先停手上的动作再开口。
- 自我形象：希望别人把他看成“靠得住、别把锅往我头上扣的人”；最怕被看成软弱、没用、只会等别人救。
- 关系记忆：对家人默认“先由我扛”，因此容易替小满做决定；与赵六共同挨板后形成一种不说出口的“别再互相坑第二回”默契。
- 感知指纹：陌生场景先看出口、谁有权、谁在看他；涉及钱先算成本，涉及危险先看可验证痕迹和退路。
- 受压时第一反应：先收信息，宁可停一下，也不抢着解释自己。
- 常用试探方式：问一个看似无关的小问题，看对方怎么接；不把手里所有证据一次亮完。
- 常用回避方式：对自己没把握的判断直接说“不知道”“只能到这里”。
- 面对上级：讲能证明什么，不抢判案权；被压时仍守住事实边界。
- 面对同级：更放松，会用一点冷幽默；必要时截住赵六乱说话。
- 面对弱者：前期不会天然同情，先看有没有风险和利益，但不喜欢逼人背没有证据的锅。
- 信息暴露阈值：除非需要换取行动或验证，不主动把全部推断告诉对方。
- 被逼到角落：先退半步找事实出口，不靠情绪硬顶。
- 禁止写法：不能现代知识全能；不能凭穿越身份天然聪明；不能一章内从普通人变神探；不能为了显聪明连续盘问别人。

## 赵六
- 年龄：29
- 身份：白役，比陈安早混县衙七年。
- 外形：瘦高，肩膀窄，灰衣挂在身上像晾着；左边门牙缺了一小角，笑起来尤其明显；眼皮常耷着，像永远没睡够。
- 习惯：兜里常装炒豆，没事就嚼；说正事时反而会把豆子收起来。
- 性格：嘴碎、惜命、消息灵、看起来滑头，真遇到同伴挨事又不会完全躲。
- 与陈安关系：前期是“同屋倒霉蛋”，既看笑话也帮忙；后期逐渐成为可靠搭档。
- 幽默方式：贫嘴、拆台、怕吃亏。
- 正常说话方式：话多，先吐槽再说正事；喜欢把严肃话题往轻里说。
- 语言指纹：先吐槽再说正事，爱把严重话题往轻里带；怕吃亏时喜欢先撇责任、说半句、把问题拐到别人身上。对上级明显收短，对同级才会贫。
- 非语言指纹：闲着会嚼豆，真事来了反而把豆子收起来；遇到风险先看上级或出口，身体常先往安全位置让半步；嘴上说不跟，脚下却可能已经跟上。
- 自我形象：希望别人觉得他滑头、懂门道、不会白吃亏；最怕被当成傻大胆或替人背锅的冤大头。
- 关系记忆：和陈安同屋、同挨板后，嘴上会先撇责任，但默认不会真把陈安单独丢在明显危险里；被周虎训过的事会记很久，见到相似场面会提前收声。
- 感知指纹：进场先看上级脸色、出口、谁可能让他担责；其次才看事情本身。看到能占便宜或能少干活的机会也会很快注意到。
- 受压时第一反应：先看上级脸色，能缩就缩；真躲不过才说。
- 常用撒谎/回避方式：装不知道、说半句、扯别人的事岔开。
- 面对上级：嘴明显变少，周虎一个眼神就会收。
- 面对同级：爱拆台、爱看热闹，也会提醒风险。
- 面对弱者：会占点嘴上便宜，但不愿真把人往死里坑。
- 信息暴露阈值：自己没好处、还有风险的消息不会主动全抖；除非事情已经把他卷进去。
- 被逼到角落：先贫嘴化解，化不开就认栽，不做英雄式硬扛。
- 禁止写法：炒豆不能每章固定出现；不能让贫嘴覆盖真正危险场景；不能突然变成胆大包天的线人。

## 周虎
- 年龄：36
- 身份：皂班班头，正式差役。
- 外形：方脸，鼻梁中过一刀留了浅痕；个子不算高但肩背厚，站着像堵门。
- 性格：粗、实际、讲县衙规矩；会打人，但不喜欢替别人擦没必要的屁股。
- 立场：不偏袒白役，也不愿真把能干的人打废。
- 与陈安关系：第一卷重要“上级门槛”，认可只来自办成事。
- 正常说话方式：短，少废话，问“证据在哪”“能证明什么”。
- 语言指纹：句子短、动词多，先要“证据在哪”“能证明什么”，很少解释自己为什么这么决定；对下属不做情绪安抚。
- 非语言指纹：先控制人和位置再说话；常用站位、挡门、把东西拿到手里复核来建立权力；不靠夸张表情，真正不满时动作反而更直接。
- 自我形象：希望别人把他看成“能压住场面、办事不拖泥带水的班头”；最怕手下乱、证据虚、最后责任落到自己头上。
- 关系记忆：对赵六的滑头早有预期，所以常直接截断废话；对陈安的评价只来自一次次办成事，不会因一场聪明表现突然改观。
- 感知指纹：进入场景先看人在哪里、谁能跑、谁能动证据、出口和现场是否失控；其次才听解释。
- 受压时第一反应：先压住场面，再拆事实；不会跟着下属一起兴奋。
- 常用试探方式：故意不表态，让对方把话说完；用实际动作复核，不接受“看起来像”。
- 面对上级：守程序，也会保自己的责任边界。
- 面对同级：看结果。
- 面对下属/白役：命令直接，不解释太多；有本事的人会多给一次机会，但不会马上亲近。
- 信息暴露阈值：不把案情推测随便告诉底层白役，只告诉他们需要执行的部分。
- 被逼到角落：先控制人和现场，再决定承担什么责任。
- 禁止写法：不能一听陈安判断就全盘相信；不能为了衬主角显蠢；不能频繁用打人代替管理。

## 刘旺
- 年龄：43
- 身份：县衙后厨杂役。
- 外形：圆脸，常年被灶火烤得两颊发红；左脚旧布鞋后跟缺一角。
- 性格：谨慎、怕事，对家里人软；最怕丢掉县衙这份活。
- 当前秘密：昨晚受孙成指使，用后厨小车把破角粮袋从西库附近移到后厨侧门，并收了五文跑腿钱；之后粮袋被别人再次移动。
- 正常说话方式：不主动惹人，遇到闲话会敷衍；说到自己可能担责的事，话立刻变少。
- 语言指纹：一旦可能担责，句子明显变短；爱把特殊行为说成“谁都这样”“天天都用”，先否认问题前提，再承认最小事实。
- 非语言指纹：受压时手会更紧地抓住正在做的活或身边物件，身体倾向往退路靠；面对正式差役时站姿会收，面对同级则会把下巴抬一点顶回去。
- 自我形象：希望自己看起来只是“听吩咐干活的人”，不是惹事的人；最怕被扣成主动偷粮、主动拿好处的主谋。
- 关系记忆：平时被白役、皂役随手使唤，知道谁是真能处置他的人；面对赵六会顶，面对周虎会明显缩。
- 感知指纹：被问事时先看谁在场、门口在哪、自己手里的活能不能继续做；只要提到西库、粮袋、钱，注意力会明显收紧。
- 受压时第一反应：否认问题的前提，不直接回答核心问题；先说“天天都这样”“谁都能用”“我哪知道”。
- 常用撒谎/回避方式：把特殊行为说成日常行为；只承认所有人都知道的部分；反问提问者凭什么这么说；把责任推给更高身份的人。
- 面对上级：明显畏缩，但也不会一开口把全部事情交代完；先承认最小事实。
- 面对同级：有底气时会顶嘴，尤其不愿被赵六这种白役拿捏。
- 面对弱者：不会主动欺负，但会用“这事跟你没关系”把人挡回去。
- 信息暴露阈值：
  1. 鞋印/车辙未被实际对上前：绝不承认昨夜推过粮。
  2. 鞋印被周虎现场复核后：只承认“推过一趟”，不主动说谁让推。
  3. 周虎明确追问来源且继续追责：才承认孙成叫他搬。
  4. 五文钱：除非周虎追问“为什么你肯搬/拿没拿好处”，否则不主动说。
  5. 粮袋后来不见：在前述事实被压实后才承认，且会强调自己以为孙成另派人处理。
- 被逼到角落：先缩、再推责任给有身份的人；如果身体威胁逼近，会快速说出能减轻自己责任的那部分事实。
- 禁止写法：不能被陈安连续问两句就老实回答；不能主动做完整时间线陈述；不能一承认就把孙成、五文钱、粮袋去向全部吐完。
- 第一章状态：与失粮路线存在直接物证关联，但不是简单脸谱化“坏人”。

## 陈小满
- 年龄：13
- 身份：陈安妹妹。
- 外形：瘦、小麦色，头发编得很紧；眼睛大，盯人时不躲。
- 性格：懂事但嘴硬，对哥哥以前欠赌债很不客气。
- 正常说话方式：直，不爱撒娇，关心人时反而容易说难听话。
- 语言指纹：直、硬，不绕着关心；常把担心说成嫌弃，把“我要参与”说成“你别把我当小孩”。句子短，但不是没内容。
- 非语言指纹：说话时手上的活通常不停；真正被戳中时动作会先停；关心人更常通过抢过东西、重新分配、把药饭推到对方面前表达，而不是说软话。
- 自我形象：希望哥哥把她当成能做事的人，而不是只需要被保护的小孩；最怕被当成累赘或什么都不懂。
- 关系记忆：原主欠债、让家里吃过苦这件事她记得很牢，所以陈安一说“我会想办法”，她天然会追问具体怎么想；和母亲之间很多照料不用说出口。
- 感知指纹：回家先看米、药、母亲状态和哥哥身上有没有新伤；谈钱时先看“今天能不能过”，不先听漂亮计划。
- 受压时第一反应：先顶一句，再想办法；不在外人面前轻易示弱。
- 常用回避方式：把担心说成嫌弃，把害怕说成“麻烦”。
- 面对哥哥：敢骂，敢管，但真出事会第一个跑。
- 面对外人/债主：警惕，不主动透露家里情况。
- 被逼到角落：先护母亲，再考虑自己。
- 禁止写法：不能写成只会乖巧等哥哥养的妹妹；不能用卖萌替代性格。

## 柳氏
- 年龄：45
- 身份：陈安母亲。
- 状态：常年咳疾，能做简单针线。
- 性格：软话少，知道家里穷，不愿儿子拿命换钱。
- 正常说话方式：声音不高，话少，不爱反复叮嘱。
- 语言指纹：声音低、话少，不重复叮嘱；自己的需求常省掉，只把孩子当前要做的事说清楚。涉及孩子冒险时语气会突然硬起来。
- 非语言指纹：多半一边做针线、收拾或照看药食一边说；不舒服时先把咳意压下去，不主动展示病弱；真正强硬时动作会停得很干净。
- 自我形象：希望孩子觉得她还能撑、不是拖累；最怕自己的病成为孩子冒险或借更多钱的理由。
- 关系记忆：知道陈安过去不够可靠，所以不会因为一次回来早、一次拿钱就立刻放心；对小满的懂事既心疼又默认她会帮忙。
- 感知指纹：先看孩子有没有受伤、有没有吃饭，再看钱；自己身体的不适反而最后处理。
- 受压时第一反应：先问孩子有没有事，再谈钱；自己的病能瞒就瞒。
- 常用回避方式：把自己的需求往后放，说“还能撑”“不用买”。
- 面对子女：不做哭诉式母亲；会指出陈安做错的地方。
- 面对外人：客气但有距离，不轻易求人。
- 被逼到角落：涉及孩子时会突然强硬。
- 禁止写法：不能只作为生病和催泪工具；不能每场都咳嗽提醒读者她有病。


## 孙成
- 年龄：34
- 身份：青溪县衙西库库吏，负责部分粮货入库、回票与日常账册。
- 外形：脸长，肤色偏黄，唇上留一撮修得很齐的短须；衣服总比旁人整洁，袖口不爱沾灰，左手食指常有洗不净的墨痕。
- 性格：精细、爱面子、身份感强；相信“手续在我手里”比拳头更可靠。怕丢差事，怕账册被翻到底，但不怕白役。
- 当前秘密：昨晚确实让刘旺把破角粮袋从西库附近转到后厨侧门；他动机并非“防漏粮”这么简单。与马二的运脚回票矛盾直接相关，但尚未冻结他是否参与马二之死。
- 正常说话方式：对下位者偏慢、带一点教训口气；遇到正式差役会立刻改成讲手续、讲规矩、讲“照例如此”。
- 语言指纹：句式完整、程序词多，喜欢把“为什么”改答成“手续上怎么做”；对下位者有教训口气，对正式差役立即切换成讲旧例、签押、责任边界。
- 非语言指纹：衣袖和账册始终保持整洁；受压时先把账本、票据摆到自己能控制的位置，手指会去抚平纸角或检查签押，不轻易后退，也少用夸张表情。
- 自我形象：希望别人把他看成“懂规矩、账上有依据、不是随便能动的人”；最怕被归为做假账、乱库规的低级失职者。
- 关系记忆：长期把白役当不懂手续的人，对周虎则知道必须讲凭据；一旦陈安多次问到程序漏洞，他会记住这个人但不会立刻承认威胁。
- 感知指纹：先看账、签押、谁拿着原件、谁有正式权力；对人的情绪变化反而不是第一关注点。
- 受压时第一反应：不否认可被账面证明的事实，而是争解释权；把异常说成惯例、误差、补录、临时处置。
- 常用撒谎/回避方式：用程序术语包住核心问题；回答“为什么”时改答“手续上怎么做”；主动挑对方不懂账务的地方反问。
- 面对上级：恭敬但不完全服软，优先拿账簿、签押、旧例保护自己。
- 面对同级差役：讲利益交换与责任边界。
- 面对白役/杂役：天然觉得他们不懂规矩，容易流露轻视；不会把陈安当真正对手。
- 信息暴露阈值：
  1. 在周虎只拿“刘旺口供”时：承认自己让刘旺搬粮，但坚持这是临时处置。
  2. 在运脚回票出现前：绝不主动承认“十八袋已经验收完成”。
  3. 回票与账面同时摆出后：改口为“先验后补账/其中一袋待复核”，争夺解释权，不直接认伪造。
  4. 三斗缺口被追问时：除非出现秤重记录、分装容器或第三人证词，不承认自己取粮。
  5. 马二之死：无直接证据前坚决切割，不因情绪承认任何关联。
- 被逼到角落：不会像刘旺一样立刻缩；会抓住程序漏洞反击，甚至指出周虎处置不合规，试图让对方顾忌责任。
- 禁止写法：不能被一张回票吓到就全盘招供；不能一见陈安就把他当聪明对手；不能用“阴笑、冷笑、脸色大变”替代真正的权力感；不能为了推进剧情主动说出自己的全部时间线。


## 刘三爷
- 年龄：约四十出头。
- 身份：青溪县民间放债人兼小额货物周转中间人；不属于县衙正式体系，但和脚夫、铺户、牙人、赌档边缘人群都有往来。
- 外形：身量不高，腰背厚，常穿洗得很干净的深色短褂；右手拇指戴一枚旧铜扳指，不显富贵，更像多年算账留下的习惯物。
- 性格：耐心、现实、记账清楚，不靠大喊大叫建立威胁；知道穷人真正怕的不是一句狠话，而是失去工作、住处、信誉和下一次借钱的可能。
- 与陈安关系：原主欠他一贯二百钱。刘三爷不把陈安当仇人，只把他当一笔正在变坏的账。
- 表层目标：按约收回本金和利钱，不让“拖欠也没后果”成为别人看到的先例。
- 深层利益：维持自己“可以借、但不能赖”的信用秩序；比起把人逼死，更希望债务人还能继续挣钱还钱。
- 正常说话方式：语速不快，句子不长，很少骂人；习惯说具体日期、数额、抵押物、谁能作保，不说空泛威胁。
- 语言指纹：说具体日期、数额、担保和后果，少形容、少威胁；别人谈人情，他会把话重新拉回“什么时候、多少、拿什么换”。
- 非语言指纹：动作少，常转旧铜扳指、看账或看可兑现物；越占优势越不逼近，常站在门边或不坐下，把“随时可以结束谈话”本身当压力。
- 自我形象：希望别人把他看成“账算得清、话说了算、可以谈但不能赖的人”；最怕自己一旦无原则松口，坏了整个放债信用。
- 关系记忆：原主多次拖欠已经让他降低信用判断；陈安后续任何一次兑现都会被记账，但不会一次翻盘。
- 感知指纹：进门先看能不能兑现的东西、家庭真实支付能力、谁在做决定；对哭穷和情绪表达关注很低，对日期、数额、工作来源极敏感。
- 受压时第一反应：先算回收概率，不先发怒。
- 常用施压方式：
  1. 缩短期限；
  2. 要求部分还款证明诚意；
  3. 找能影响债务人工作的中间人递话；
  4. 要求可兑现的抵押或担保；
  5. 在对方公开失信前，给一次明确但有限的缓期。
- 常用回避方式：别人把债务讲成“人情”时，他会重新拉回数额、日期和承诺；别人哭穷时，他不争真假，只问“你能拿什么保证”。
- 面对比自己弱的人：不需要粗暴，反而更平静；越确定自己占优势，越少说狠话。
- 面对县衙正式差役：会留足面子，不正面冲撞，但会记住谁替谁说过话。
- 面对陈安：前期默认他信用很差，不因为一次聪明表现就改观；只认连续兑现。
- 信息暴露阈值：
  1. 不主动讲自己还有哪些债户、关系和货路。
  2. 陈安只说“再宽限几天”时，不接受空口。
  3. 陈安能拿出明确收入来源或先还一部分时，才谈延期。
  4. 若有人替陈安作保，他先判断担保人的可兑现性，而不是看关系亲疏。
- 底线：
  - 不接受连续失约又无任何补偿；
  - 不接受拿柳氏治病所需之物做明显无法兑现的空头抵押；
  - 不因一时愤怒做让本金彻底收不回的事；
  - 不替陈安遮掩新的赌债。
- 被逼到角落：如果陈安真没有可回收资产，他会转向长期绑定收入或工作渠道，而不是突然变成街头恶霸。
- 让步边界：可以延期、分期、换担保，但每次让步必须换到更高确定性；不会“看你可怜就算了”。
- 禁止写法：
  - 不能一出场就带打手砸门、抢药、卖妹妹；
  - 不能用“阴恻恻”“狞笑”“舔刀口”代替压力；
  - 不能因主角一句聪明话就欣赏主角、主动送机会；
  - 不能无理由把合法/半合法债务升级成生死追杀；
  - 不能为了制造爽点故意算错账或被陈安轻易说服。
