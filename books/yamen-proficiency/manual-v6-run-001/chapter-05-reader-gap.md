# 第五章 Reader Gate · Reader Gap Review

## RG001
【类型】semantic-gap
【逐字片段】“县衙那边也没完。”

【读者实际理解】
读者知道“县衙有麻烦”，但无法一次阅读确认这句话具体指：
- 案子还没结束；
- 陈安的差事还没结束；
- 还是陈安仍有被牵连风险。

【作者预期】
这里本意是让陈安有限承认：
1. 县衙里的事情尚未结束；
2. 他今天仍要回去；
3. 他不知道自己会不会被牵连。
作者并不打算告诉家人具体案情。

【为什么不是有效留白】
有效留白应当让读者清楚“未知项是什么”。这里连被省略的对象都不稳定，读者不知道自己究竟缺的是“案情详情”还是“陈安个人风险”。这是语义支点缺失，不是悬念。

【修改边界】
只补足“县衙还有事 / 陈安还得回去”这一层必要对象，并把“是否牵连他”留在后续问答中。
不得增加马二、孙成、失粮细节，不得让陈安全盘坦白。

## RG002
【类型】semantic-gap / salience-gap
【逐字片段】“事情没收尾。”

【读者实际理解】
能大致猜到县衙有事，但与后文“县衙那边也没完”连续使用两个泛指词，造成信息重点漂移。

【作者预期】
本场重要的不是案件内容，而是“陈安必须回县衙且仍有风险”。

【为什么需要调整】
单独出现一次可以作为人物回避；连续两次都使用无对象泛指，会让读者把注意力放在“到底什么事”这个字面困惑上，而不是人物隐瞒行为。

【修改边界】
前一处允许保持一定回避，但至少其中一处必须给出实际行动对象，如“我还得回县衙”。
