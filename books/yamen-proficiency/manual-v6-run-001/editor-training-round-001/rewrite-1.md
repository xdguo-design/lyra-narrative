# Editor Rewrite 1

周虎把钥匙在掌心里一拍：“里头今晚有人进出，后门不能空。”

赵六张口：“班头，我昨晚——”

周虎没接话。

赵六自己把话拐了个弯：“我昨晚其实睡得还成，今儿精神也不算差。”

“那你留？”

“要说熬一夜，也没精神到那个份上。”

周虎等着，不替他把话说完。

陈安往院门外看了一眼。现在走，天黑前能到城南；昨天小满已经跑过一次县衙，今天中午他才让她别再来。今晚如果又不回去，家里听见的就只剩一句“等我回来”。

“夜值有钱吗？”

周虎道：“没有。”

“明早能歇？”

“看有没有活。”

“那就是不一定。”

“嗯。”

赵六往陈安旁边挪了半步：“你还问？再问下去，真像咱俩有得挑。”

周虎听见了，只把钥匙放到窗台上。

“有。你们自己定。”

他转身前留下一句：“半刻钟后，后门要有人。”
