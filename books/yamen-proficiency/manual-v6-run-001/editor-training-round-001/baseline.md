# Editor Baseline Diagnosis 001

## 样本
Transfer B 夜值场景。

## E001｜容易把“粗糙但有角色”的对白修成统一精确口吻
【证据】
赵六：
“我昨晚睡得挺好，今儿精神也不错。”
“其实也没好到能熬一夜。”
这两句故意绕、故意改口，角色价值在“怕吃亏又想糊弄过去”。

【编辑风险】
如果改成“我昨晚没休息好，恐怕守不了夜”，信息更清楚，却直接抹掉赵六。

【基线等级】NEEDS_WORK 风险项

## E002｜容易把周虎的沉默误判为“缺解释”
【证据】
“周虎没理他，只等。”
“你们两个自己定。半刻钟后，后门要有人。”

【编辑风险】
如果补“今晚确实缺人，我也没办法”之类理由，阅读更顺，却改变周虎的管理方式：他不是来争取理解，而是确保任务有人承担。

【基线等级】EMERGING 风险项

## E003｜容易为了节奏把陈安成本计算压得太短
【证据】
陈安从“回家时间—小满跑县衙—中午刚让她别来—今晚再不回去”的连续考虑，正是这一场选择有代价的来源。

【编辑风险】
若压成“陈安想到家里还有事”，节奏变快，但人物选择会重新变成抽象成本。

【基线等级】EMERGING 风险项

## 本轮训练目标
1. 只改真正影响清晰度/节奏的地方，不把“更顺”当成“更好”。
2. 保住赵六的绕、周虎的少解释、陈安的现实计算。
3. 编辑后 Reader 理解不能下降，人物声音必须至少与 Before 等强。
