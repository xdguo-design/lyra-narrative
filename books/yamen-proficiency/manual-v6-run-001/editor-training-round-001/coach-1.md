# Editor Coach 001

## 结果
FAIL / NEEDS_WORK

### EF001｜voice
【原文】
赵六：“我昨晚睡得挺好，今儿精神也不错。”
“其实也没好到能熬一夜。”

【编辑稿】
“我昨晚没休息好，恐怕守不了夜。”

【失败原因】
信息更清楚，但赵六从“先装好、再立刻改口”的滑头变成普通员工请假。角色声音被编辑统一成准确表达。

【必须保留】
赵六现场看脸色、改口、绕着成本说话的行为。

【重写边界】
可压字，不可把绕口改成直接说明。

### EF002｜voice / fact-intent
【编辑稿】
周虎：“总得有人守。”

【失败原因】
新增了周虎解释理由的句子。原稿中“门不能空”已经是任务边界，周虎不会再为自己辩解“总得有人”。

【必须保留】
周虎不求下属理解，只要结果。

【重写边界】
删除新增解释，不得补管理者心理。

### EF003｜selection / overedit
【原稿】
陈安对回家、小满、自己中午刚做的安排进行连续成本计算。

【编辑稿】
“可要是留下，今晚就只能让家里继续等他。”

【失败原因】
把具体关系代价压成抽象“家里等他”，编辑虽然更快，却把陈安为什么犹豫削薄。

【必须保留】
小满前一天跑县衙、当天中午刚被陈安要求别来，这两个具体关系事实。

【重写边界】
可以压缩句式，不可删掉代价来源。

## 通过标准
- 赵六仅凭对白仍能辨认。
- 周虎不新增解释。
- 陈安的选择仍有具体家庭代价。
- After Reader 对三人目标的理解不得弱于 Before。
