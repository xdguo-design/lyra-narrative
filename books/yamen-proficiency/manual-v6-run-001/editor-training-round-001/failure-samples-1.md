# Editor Failure Samples 001

EDITOR_FAILURE_V1

## EF001
【原文】
“我昨晚睡得挺好，今儿精神也不错。”
“其实也没好到能熬一夜。”

【编辑稿】
“我昨晚没休息好，恐怕守不了夜。”

【失败类型】voice / overedit
【为什么失败】把赵六的现场改口和滑头口吻修成准确汇报。
【必须保留】绕、改口、怕吃亏。
【重写边界】允许压字，不允许直译成意思。
【复审结果】PASS after Rewrite 1

## EF002
【编辑新增】
“总得有人守。”

【失败类型】fact-intent / overedit
【为什么失败】替周虎新增解释动机，改变管理风格。
【必须保留】周虎只给边界，不求理解。
【重写边界】删除新增解释。
【复审结果】PASS

## EF003
【原事实】
昨天小满跑过县衙；今天中午陈安刚让她别再来。

【编辑稿】
“家里继续等他。”

【失败类型】selection
【为什么失败】把具体关系代价压成抽象概括。
【必须保留】至少两个具体家庭事实中的关键因果链。
【重写边界】可缩句，不可抽空。
【复审结果】PASS
