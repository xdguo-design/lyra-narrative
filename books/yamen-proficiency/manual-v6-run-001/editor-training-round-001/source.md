# Editor Training Source｜Transfer B 原始稿节选

周虎把钥匙往掌心里一拍：“里头今晚有人进出，门不能空。”

赵六立刻道：“班头，我昨晚——”

周虎看了他一眼。

赵六把后半句换了：“我昨晚睡得挺好，今儿精神也不错。”

“那你留？”

“其实也没好到能熬一夜。”

周虎没理他，只等。

陈安朝院门外看了一眼。这个时辰回城南，正好能赶在天黑前到家。昨天挨板子以后，小满已经跑过一次县衙；今天中午他才让她别来，自己晚上要是又不回去，解释起来比守门麻烦。

“夜值有钱吗？”他问。

赵六扭头看他，眼神里带了点佩服。

周虎道：“没有。”

“明早能歇？”

“看有没有活。”

“那就是也不一定。”

“嗯。”

周虎答得很干脆。

赵六凑近半步，压低声音：“你还问什么？问多了容易显得咱们真有得选。”

周虎听见了。

“你确实有。”

赵六眼睛一亮。

“你们两个自己定。半刻钟后，后门要有人。”

说完，周虎把钥匙放到窗台上，转身走了。
