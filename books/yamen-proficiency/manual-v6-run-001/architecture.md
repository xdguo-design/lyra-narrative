# 《穿成县衙白役，我把熟练度肝满了》故事架构

## 定位
- 类型：架空历史 / 穿越 / 底层成长 / 熟练度金手指 / 县衙日常与小案
- 阅读目标：大众网文，可轻松进入；爽点清楚但不无脑；人物有生活气，语言顺，有轻微幽默。
- 核心卖点：主角没有显赫身份，也没有礼包商城，从县衙最底层的白役开始，用可重复、可验证的熟练度成长，一点点把“随时能被替掉的人”变成“别人离不开的人”。

## 核心命题
底层人真正缺的往往不是一次好运，而是“今天学会的东西明天不会白费”。熟练度面板把这一点变成确定性，但真正决定主角能走多远的，仍然是选择、关系和代价。

## 主角起点
陈安，二十一岁，穿越到架空王朝大梁青溪县一个同名白役身上。
白役不是正式差役，没有稳定俸禄，脏活累活抢着上，出了事却最容易先挨板子。
原主家里有病母和十三岁的妹妹，另欠本地放贷人一贯二百钱。
故事开始前一天，县衙转运赈粮时少了一袋米，陈安与另外三名白役因当值不清，每人先挨十五板。

## 长线成长
第一阶段（1—30章）：县衙站稳
- 找回失粮，避免继续背锅。
- 接触东街尸案，熟练度第一次用于正式差事。
- 从“谁都能使唤”变成周班头愿意带着办事的人。
- 处理债务与家庭困境。
- 获得转为正式皂役/捕役的机会。

第二阶段（31—100章）：县里有名
- 追逃犯、查赌坊、乡里械斗、粮税猫腻。
- 学会刀棒、追踪、验伤、文书、识人。
- 与县衙内部既得利益产生冲突。
- 主角开始有自己的同伴和底线。

第三阶段（100章后）：从县到府
- 能力与身份同步上升，但不跳级开挂。
- 案件从个人生计扩大到地方利益与官场秩序。
- 金手指只提供“学得会”，不能替主角做政治选择。

## 第一卷核心冲突
“一个没有正式身份的人，怎样让自己不再成为出了事就被推出去挨打的那个。”

## 第一章任务
1. 让读者在两页内明白主角处境：穿越、白役、挨打、缺钱。
2. 用动作而不是百科说明建立县衙后院和白役身份。
3. 让赵六第一次出场就有外貌、神态、口吻和生活感。
4. 金手指第一次出现，但不解释成系统说明书。
5. 主角自行发现粮袋移动路线，系统只在“成功完成一次真实寻迹”后记录技能，不负责指出线索。
6. 章末落在具体嫌疑人/证据上，不用作者总结句。
