# Editor Attempt 2｜家庭/经济迁移

院里晒着两件洗过的旧衣，风一吹，袖子空荡荡地往墙上拍。

陈小满坐在门槛边拆旧线团。剩线颜色杂、长短不齐，她一截截接起来，旁边已经绕出拳头大的一团。陈安回来时，她正把最后一个结咬紧。

“明天我去西街。”

陈安把水瓢放回缸边：“干什么？”

“布庄赶一批秋衣，缺人锁边。周婶说一天能算二十件，做得快有八文。”

“你不去。”

“我还没问你。”

“我听见了。”

“听见就算你答应了？”

陈安把她脚边的线团拿起来。几种颜色接得乱，结却打得紧。

“你什么时候开始接这个活的？”

“娘做不过来的时候。”

“做多久了？”

“跟你欠债差不多久。”

陈安把线团放回去。

小满继续理线：“布庄这次给得比平时多。”

“多是因为急。”

“急才有钱。”

“急就得熬夜。”

“我十三，不是三岁。”

“十三也不用拿眼睛换八文。”

小满抬头：“那拿什么换？”

她把接好的线绕到木板上，一圈圈压紧。

“你现在有钱？”

“没有。”

“有能马上拿到钱的活？”

“没有。”

“那为什么我有，你就不让我去？”

陈安道：“赶工伤眼。”

“娘天天做针线的时候你怎么没说？”

屋里的柳氏把没缝完的袖口翻了个面，没有插话。

“娘是娘，你是你。”

小满笑了一声：“这话真省事。”

她起身去拿墙边的小布包，陈安伸手按住。

“明天别去。”

小满不抢，只看着他的手。

“刘三爷的人见过我。”

“所以更不能让你一个人在外面跑。”

“西街布庄白天几十号人。”

“人多不等于没事。”

“那我以后是不是都不用出门？”

陈安的手没有松。

“等你什么时候有钱了，我才能出去？”

债主、夜路、赶工、布庄压价，他能列出的风险都是真的，可哪一样也变不出明天的米和药。

屋里传来布料摩擦声。

柳氏把衣袖放到桌边：“这件明晚要交。还有三件没锁边，我今晚做不完。”

她把针插回针线包，不再说了。

小满伸手去拿布包。

这次陈安没按住。

“周婶跟你一起？”

“她领我们去，散工后一起回来。”

“几点散？”

“不一定。”

小满把布包背到肩上：“你可以不同意。”

走过陈安身边时，她停了一下。

“反正你也没有更好的办法。”

院门合上以后，那团接好的线还留在门槛边。

柳氏从屋里道：“别踩。”

陈安把脚挪开。

那团线接了十几个结，没有一个散。
