# Editor Selection Exercise 002｜家庭/经济迁移

## Source
Writer Transfer A：陈小满准备去布庄赶工。

| 片段 | 决策 | 理由 |
| --- | --- | --- |
| 开头旧衣 + 旧线团 | PRESERVE | 两个细节共同建立家庭劳动状态，但不继续扩写。 |
| “跟你欠债差不多久。” | NO_TOUCH | 小满声音强，关系历史浓缩在一句里。 |
| “急才有钱。” | NO_TOUCH | 口语短、硬，不能改成完整说明。 |
| “我十三，不是三岁。” | NO_TOUCH | 人物边界句，不能编辑成抽象“我能帮家里”。 |
| “显然不是刚学。” | CUT | 线团、结打得紧、后续对话已经能证明，不需解释。 |
| “这句话他答不上来。” | CUT / MERGE | 后面的现实风险与钱已经体现他的失语，解释可减。 |
| 陈安列风险段 | PRESERVE / COMPRESS | 必须保留具体风险，避免变成抽象“他担心妹妹”。 |
| 柳氏“还有三件没锁边” | NO_TOUCH | 具体生活事实介入，不可扩成母爱说明。 |
| “你可以不同意。反正你也没有更好的办法。” | PRESERVE | 小满没有求同意，而是指出陈安缺替代方案。 |
| 结尾线团十几个结 | PRESERVE | 具体画面，不补主题句。 |
