## EF004｜Near-miss rejected edit
【原文】
“娘是娘，你是你。”

【危险编辑候选】
“娘身体不好，你还小，情况不一样。”

【失败类型】voice / overedit
【为什么失败】
候选句更完整、更讲理，却把陈安此刻说不圆、靠身份区分来维持控制的缺点修掉。

【必须保留】
陈安在关系处理上的生硬与不充分理由。

【重写边界】
若无语义障碍，NO_TOUCH。

【复审结果】
REJECTED BEFORE APPLY / PASS
