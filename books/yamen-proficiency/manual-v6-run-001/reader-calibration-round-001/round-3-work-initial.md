# Reader Calibration Round 3｜Transfer B 上级 / 工作场景

## Reader A — 首读理解
【发生了什么】
周虎让陈安和赵六二选一守后门。赵六想躲，陈安算清没有钱、也未必能休息后仍决定留下，因为他把这种麻烦差事当成身份投资，同时托赵六去家里传话。

【需要回读】
### RC001 — AMBIGUOUS_GAP
原句：
“等赵六到了城南，小满大概已经知道今晚那扇门不用等了。”

第一次读时，“那扇门”存在两个同样合理的指向：
1. 县衙后门——前文连续写后门、门栓、钥匙；
2. 城南家门——作者真正想表达的是小满不用等陈安回家。

我可以猜到作者更可能想写家门，但当前最近的实体是县衙后门，造成指代竞争。

【A 结果】
LOCAL_REWRITE

## Reader B — 人物 / 关系
【周虎】
目标是后门有人值守，不负责照顾两人的生活成本。

【赵六】
想躲无收益夜值，但愿意替陈安跑一趟家里。

【陈安】
把夜值视作职业投资，但代价是再次失约于家庭。

【关系变化】
- 陈安与赵六：从互相推差事，到形成一次有边界的同伴帮助。
- 陈安与家庭：正文意图是产生“今晚又回不去”的关系成本。

【关系问题】
RC001 会削弱最后一个家庭关系落点，因为读者注意力被“这扇门到底是哪扇”打断。

【B 结果】
LOCAL_REWRITE

## Reader C — 阅读动力
【最想继续看的问题】
陈安承担无收益夜值是否真的会换来职业位置，以及小满对再次失约会有什么反应。

【问题】
最后一句本应把动力从“守门任务”切到“家庭后果”，但“那扇门”的歧义让读者短暂回到县衙后门，削弱了下一场期待。

【C 结果】
LOCAL_REWRITE

## 处置
RC001 = AMBIGUOUS_GAP / LOCAL_REWRITE
