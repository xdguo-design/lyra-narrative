## 10. Story State Usage

正式重写从 Chapter 1 开始，因此：
- 不直接续写旧 Chapter 4 Story State；
- 旧 chapter-01-final 至 chapter-04-final 只作为“已验证事实/问题样本”参考；
- 正文重新生成；
- 不复制旧句子来“拼装新版”。

必须保留的故事级事实来自 architecture / character / proficiency 冻结文件，而不是旧稿措辞。

## 11. Rewrite Workflow

每章：

Chapter Promise Card
→ Scene Director
→ Writer
→ Blind Reader A/B/C
→ Character / Continuity / Plot / World Review
→ Editor
→ Blind Reader Recheck
→ Failure Corpus Regression
→ Final Review
→ Story State 更新

blocking 未清零，不进入下一章。

## 12. Chapter-Level Hard Rules

- 一章一个主要发动机。
- 连续三章不得都是调查。
- 不能为了推进剧情让人物突然诚实。
- 不能为了爽点让陈安连续全对且无代价。
- 不能让新线索跟着主角脚步准时掉落。
- 不能按章弹系统。
- 不能用 AI 总结式结尾。
- 不能把家庭写成温情插曲。
- 不能让身份只存在于称呼。
- 不能用“高级感”删除必要语义支点。
