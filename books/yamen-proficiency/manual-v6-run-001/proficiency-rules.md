# 熟练度金手指规则 v1

## 表现形式
只有陈安能看到极简文字面板。系统没有人格，不聊天，不发布任务，不签到，不抽奖，不开商城。

## 核心规则
1. 只有真正做过、并形成有效学习的行为，才会被记录为技能熟练度。
2. 系统不提前指出“什么是线索”“谁在撒谎”“答案是什么”。它不能替主角判断世界。
3. 技能首次出现，必须建立在一次真实行为已经产生结果之后。例如陈安成功完成一次寻迹，才出现【寻迹】；不是看见一粒米就自动告诉他这是线索。
4. 无意义重复、机械刷动作、没有反馈的乱试，收益会快速下降到零。
5. 熟练度提升改善的是动作控制、经验调用、观察习惯和稳定性，不直接凭空增加外部知识。
6. 身体是硬上限。刀法再高，虚弱时仍会累；受伤时仍会影响动作。
7. 认知技能不能生成没见过的信息。验尸熟练度不能让他知道不存在于现场的证据；文书熟练度不能让不识字的人凭空认字。
8. 技能突破不会消除代价。学得快不代表社会身份自动提高，也不代表别人会因此信任他。

## 等级
每个技能按阶段显示：
- 初学
- 入门
- 熟练
- 精通
- 大成

每一阶段内部使用 0/100 进度。达到 100 进入下一阶段，进度重置。
前期只展示与剧情有关的技能，禁止面板刷屏。

## 第一章使用边界
- 陈安先靠自己发现米粒、拖痕、麻布纤维、车辙等痕迹。
- 当他把这些痕迹串成一条真实路线，并找到可验证的落点后，系统才首次记录【寻迹】。
- 系统不告诉他刘旺是否为真凶，只记录他完成了有效寻迹。
- 第一章不升级，不给奖励包，不增加属性点。
