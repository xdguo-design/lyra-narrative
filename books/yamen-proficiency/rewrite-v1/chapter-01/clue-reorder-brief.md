# Chapter 01 Clue Reorder Brief｜普通读者视角

## 当前阅读问题
旧后半段呈现：
米粒 → 擦痕 → 蓝线 → 车辙 → 脚印 → 精准记忆 → 系统 → 赵六认车 → 刘旺准时推车出现 → 鞋印吻合。

单个节点都可解释，但连续排列后形成“线索阶梯”和“巧合聚集”。

## 重排原则

### 1. 刘旺 / 小车提前进入背景
两人刚进后院时，刘旺正常推泔水车经过。
此时：
- 只作为后院日常；
- 赵六最多自然让路/叫一声；
- 陈安只注意车轮一边发涩，因为需要侧身避车；
- 不看鞋、不判断嫌疑。

目的：
后面再想到这辆车，是回扣，不是作者临时把人送到镜头前。

### 2. 米粒只负责制造“位置异常”
- 只有零散米粒；
- 不形成面包屑式连续路径；
- 后院本来就可能有米，所以不能直接当证据。

看到米以后才询问正常运粮路线。

### 3. 擦痕给方向，但必须中断
- 墙根有新旧难分的擦痕；
- 陈安顺过去；
- 到木棚后痕迹被扫帚印、旧脚印、车轮印淹没；
- 第一次追踪失败，不能一路自动通关。

### 4. 车辙先于蓝线形成“可比较对象”
在杂乱地面中只找到一段较新的窄轮印，一边深一边浅。
陈安想到刚才经过的那辆偏车，但：
- 后厨小车不是刘旺一人能用；
- 车辙也不能证明运过失粮。

### 5. 系统在“完成真实寻迹”后记录
系统出现时只对应：
- 从噪声中辨别新旧痕迹；
- 找到一段可持续比较的轮印。

此时尚未确认蓝线、失粮袋或刘旺。
避免 SYSTEM_CONFIRMATION_LEAK。

### 6. 蓝线后出现，而且仍然不够
木棚铁钉挂蓝麻线。
赵六指出蓝麻线并不稀奇。

陈安通过触感触发一段不完整旧记忆：
- 昨日确实搬过一只右下角用蓝线粗缝的粮袋；
- 但不能证明现在这根线就是那只袋留下；
- 更不能证明那只袋就是最终缺失的一袋。

### 7. 脚印成为独立待核查项
木棚附近潮处留一个左后跟缺角的较完整脚印。
不紧接着出现刘旺的鞋。
先记录，不认人。

### 8. 主动去核对，而不是等巧合送上门
赵六说刚才那辆车是刘旺常用的泔水车，但后厨谁都可能碰。
陈安决定去后厨看看车。

到后厨：
- 车停在那里；
- 刘旺正在冲洗/收拾车，本来就在工作；
- 轮距和偏轮可核对；
- 刘旺转身/踩住车轮时露出左鞋后跟缺角。

章尾：
三项事实集中到同一“需要核查的人”：
车常由刘旺使用 + 车轮特征可比 + 左鞋缺角。
仍不能证明刘旺偷粮。

## 必须保留
- 米粒；
- 墙根擦痕；
- 蓝麻线；
- 窄车辙一深一浅；
- 左脚后跟缺角；
- 【寻迹·初学 1/100】；
- 刘旺 43 岁、后厨杂役、圆脸灶火熏红；
- 刘旺只成为需要核查的人；
- 第二章必须由周虎实际复核。

## 必须减少
- 连续两步必有新线索；
- “刚需要谁，谁就出现”；
- 原主记忆精准补最后拼图；
- 系统紧跟结论；
- 作者解释“这只能证明什么”的重复声明。

## 本段 Narrative Function Contract
1. 陈安发现失粮可能偏离正常入库路线。
2. 陈安第一次完成真实寻迹动作，系统记录技能。
3. 陈安得到“需要核查刘旺及其小车”的合理依据。
4. 不确认偷粮者，不确认粮袋去向。
5. 章尾仍有具体人物冲突入口，但不是巧合送上门。
