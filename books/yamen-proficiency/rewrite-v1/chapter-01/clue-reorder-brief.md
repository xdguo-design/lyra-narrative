# Chapter 01 Clue Reorder Brief｜普通读者视角

## 当前阅读问题
旧后半段呈现：
米粒 → 擦痕 → 蓝线 → 车辙 → 脚印 → 精准记忆 → 系统 → 赵六认车 → 刘旺准时推车出现 → 鞋印吻合。

单个节点都可解释，但连续排列后形成“线索阶梯”和“巧合聚集”。

## 重排原则

### 1. 刘旺 / 小车提前进入背景
两人刚进后院时，刘旺正常推泔水车经过。
此时：
- 只作为后院日常；
- 赵六最多自然让路/叫一声；
- 陈安只注意车轮一边发涩，因为需要侧身避车；
- 不看鞋、不判断嫌疑。

目的：
后面再想到这辆车，是回扣，不是作者临时把人送到镜头前。

### 2. 米粒只负责制造“位置异常”
- 只有零散米粒；
- 不形成面包屑式连续路径；
- 后院本来就可能有米，所以不能直接当证据。

看到米以后才询问正常运粮路线。

### 3. 擦痕给方向，但必须中断
- 墙根有新旧难分的擦痕；
- 陈安顺过去；
- 到木棚后痕迹被扫帚印、旧脚印、车轮印淹没；
- 第一次追踪失败，不能一路自动通关。

### 4. 车辙先于蓝线形成“可比较对象”
在杂乱地面中只找到一段较新的窄轮印，一边深一边浅。
陈安想到刚才经过的那辆偏车，但：
- 后厨小车不是刘旺一人能用；
- 车辙也不能证明运过失粮。

### 5. 系统在“完成真实寻迹”后记录
系统出现时只对应：
- 从噪声中辨别新旧痕迹；
- 找到一段可持续比较的轮印。

此时尚未确认蓝线、失粮袋或刘旺。
避免 SYSTEM_CONFIRMATION_LEAK。

### 6. 蓝线后出现，而且仍然不够
木棚铁钉挂蓝麻线。
赵六指出蓝麻线并不稀奇。

陈安通过触感触发一段不完整旧记忆：
- 昨日确实搬过一只右下角用蓝线粗缝的粮袋；
- 但不能证明现在这根线就是那只袋留下；
- 更不能证明那只袋就是最终缺失的一袋。

### 7. 脚印成为独立待核查项
木棚附近潮处留一个左后跟缺角的较完整脚印。
不紧接着出现刘旺的鞋。
先记录，不认人。

### 8. 主动去核对，而不是等巧合送上门
赵六说刚才那辆车是刘旺常用的泔水车，但后厨谁都可能碰。
陈安决定去后厨看看车。

到后厨：
- 车停在那里；
- 刘旺正在冲洗/收拾车，本来就在工作；
- 轮距和偏轮可核对；
- 刘旺转身/踩住车轮时露出左鞋后跟缺角。

章尾：
三项事实集中到同一“需要核查的人”：
车常由刘旺使用 + 车轮特征可比 + 左鞋缺角。
仍不能证明刘旺偷粮。

## 必须保留
- 米粒；
- 墙根擦痕；
- 蓝麻线；
- 窄车辙一深一浅；
- 左脚后跟缺角；
- 【寻迹·初学 1/100】；
- 刘旺 43 岁、后厨杂役、圆脸灶火熏红；
- 刘旺只成为需要核查的人；
- 第二章必须由周虎实际复核。

## 必须减少
- 连续两步必有新线索；
- “刚需要谁，谁就出现”；
- 原主记忆精准补最后拼图；
- 系统紧跟结论；
- 作者解释“这只能证明什么”的重复声明。

## 本段 Narrative Function Contract
1. 陈安发现失粮可能偏离正常入库路线。
2. 陈安第一次完成真实寻迹动作，系统记录技能。
3. 陈安得到“需要核查刘旺及其小车”的合理依据。
4. 不确认偷粮者，不确认粮袋去向。
5. 章尾仍有具体人物冲突入口，但不是巧合送上门。

## 第二轮线索密度重排｜蓝线 / 记忆 / 脚印

### 普通读者问题
当前木棚附近仍连续给出：
短轮印 → 蓝线 → 立即回忆蓝线补袋 → 木棚后缺角脚印。

虽然每项都不是答案，但单位空间内高价值异常过密，仍像“木棚证据箱”。

### 新间隔

#### A. 木棚只留两项
1. 一小段偏轮特征的窄轮印；
2. 铁钉上的蓝麻线。

蓝线只被看见、保留，不当场触发完整记忆，不在木棚后继续发现缺角脚印。

#### B. 离开木棚后才出现记忆
两人已经决定去后厨核车，并走出木棚区域。
蓝线的颜色在陈安脑中压了一会儿，走到窄道后才迟到地带出昨日搬粮时“袋角粗线扎过手腕”的短记忆。

要求：
- 记忆不是即时弹窗；
- 只确认昨日搬运批次里见过蓝色粗补线；
- 仍不能确认那只袋就是失粮袋；
- 记忆出现后不立即奖励新线索。

#### C. 脚印移到通后厨的湿窄道
脚印不再属于木棚证据簇。
放在后厨外排水/泼水形成的湿泥处，和木棚之间有实际行走距离、对话和记忆间隔。

要求：
- 现场有多个杂乱脚印；
- 只有一枚左后跟外沿缺角相对清楚；
- 因位置靠近后厨，它本身反而更不能直接锁定刘旺；
- 只作为稍后核鞋的待比较特征。

### 新阅读节奏
木棚短轮印
→ 蓝线（暂存）
→ 离开木棚
→ 讨论是否去核车
→ 窄道途中迟到记忆
→ 继续走
→ 后厨外湿地缺角脚印
→ 到后厨核车
→ 章尾刘旺鞋后跟特征进入同一比较范围。

### 目标
让三条高价值信息分别发生在：
- 一个物件位置；
- 一段人物内部回忆；
- 一个新的空间位置。

避免在同一两三米内连续发放“蓝线 + 记忆 + 脚印”。
