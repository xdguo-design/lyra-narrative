# Chapter 01 Clue Density Reader Recheck

视角：第一次阅读的普通读者。
目标：检查蓝线 / 记忆 / 脚印是否仍然挤在木棚附近连续发放。

## 1. 蓝线
位置：木棚立柱。
作用：只记录“这里有蓝色麻线”，不立即兑现完整含义。

PASS

读者此时知道：
- 蓝线存在；
- 赵六认为蓝线很常见；
- 陈安没有把它扯下来，也没有直接拿它下结论。

## 2. 记忆
位置：已经离开木棚，进入通后厨的窄道。

PASS WITH WATCH

变化：
- 不再“碰到蓝线 → 立刻弹出完整记忆”；
- 蓝线在脑中停留一段时间后，才迟到想起昨日某只麻袋用蓝色粗线补过；
- 赵六追问“哪只”，陈安明确回答“不知道”。

这使记忆只补充背景，不补齐答案。

WATCH：
“木棚被甩到身后，陈安脑子里那点蓝色却没散”仍略带作者安排延迟感。后续若同类回忆反复用“线索在脑中盘旋 → 迟到想起”，应判模式化。

## 3. 无新线索间隔
位置：窄道。

PASS

两个厨役抬菜梗经过：
- 没有提供新证据；
- 只是让人物让路、伤势继续存在；
- 给记忆与下一条线索之间提供真实生活节奏。

这一步有效降低“每走一步都有奖励”的感觉。

## 4. 脚印
位置：靠近后厨的排水沟湿泥，不再属于木棚区域。

PASS

作用：
- 与蓝线空间分离；
- 与记忆之间有实际行走、对话和生活动作；
- 靠近后厨意味着很多人可能经过，因此脚印本身更不能锁定刘旺。

## 5. 阅读密度
旧：
木棚轮印 → 蓝线 → 即时记忆 → 木棚后脚印。

新：
木棚轮印
→ 蓝线
→ 离开木棚
→ 核车对话
→ 进入窄道
→ 迟到记忆
→ 人物让路 / 无新线索
→ 排水沟脚印
→ 后厨核车。

结果：
CLUE_DENSITY_GAP：明显下降。

## 6. 章尾推进
PASS

仍然保留：
- 车轮特征可比较；
- 蓝线作为弱关联；
- 缺角脚印作为独立待比较特征；
- 最终刘旺鞋后跟进入同一比较范围。

但三条信息不再从同一地点连续吐出。

## Verdict
PASS

Blocking：0
Watch：delayed-memory phrasing only.
