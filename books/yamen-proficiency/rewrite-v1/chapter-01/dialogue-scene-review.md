# Chapter 01 Dialogue Authenticity Review｜陈安 × 赵六

DIALOGUE_AUTHENTICITY_V1

VERDICT: PASS WITH LOCAL_POLISH

## 场景目标 A｜陈安
补齐失粮与处罚信息，判断是否值得下地看现场；同时不暴露自己记忆断裂和身体虚弱。

## 场景目标 B｜赵六
确认陈安是不是被打坏了脑子；阻止自己再次被拖进麻烦；如果陈安真要去，先把责任撇开。

## 去名字测试
PASS

### 陈安可识别
典型：
- “西库那袋粮，找着没有？”
- “周班头怎么说？”
- “我想先看看昨天那袋粮本来该怎么走。”
- “正常从哪儿进？”
- “有没有理由绕后院。”

特征：
- 问题短；
- 只问事实；
- 不解释真实焦虑；
- 不求人陪；
- 不给结论。

### 赵六可识别
典型：
- “找着了，我还在这儿陪你站着？”
- “你别问我‘怎么个不清净’。”
- “咱俩昨天已经替那袋破粮挨过一回。今天最好谁也别再替它长记性。”
- “我先跟你说好，按理归按理。真有人不按理，你别指望我替你按住。”
- “说好了，我是出来透气。”

特征：
- 先把严重事说轻；
- 先撇责任；
- 嘴上不跟，身体跟上；
- 不承认自己是在帮忙。

## 换人测试
PASS

将“说好了，我是出来透气”换给陈安明显失真。
将“我想先看看昨天那袋粮本来该怎么走”换给赵六也失真。

## 声音指纹
PASS

陈安：
事实型、少说、不解释、不求陪。

赵六：
贫、绕、先保自己、真事来了逐渐收起玩笑。

## 面子 / 自我保护
PASS

陈安：
- 用“疼得有点乱”遮住记忆断裂；
- 不承认自己需要赵六帮忙；
- 疼时自己撑住。

赵六：
- 不直说“我怕再挨打”；
- 把风险包装成“屁股还结实”“别替破粮长记性”；
- 跟上后仍强调“出来透气”。

## 关系旧账
PASS

“咱俩昨天已经替那袋破粮挨过一回”把共同挨板变成真实关系记忆。
这不是新增背景，而是把已冻结事实转成双方共有的说话前提。

## 身体 / 表情 / 并行任务
PASS

- 两人都刚挨板，站、坐、弯腰、迈门槛都受影响。
- 赵六从嚼豆到收豆，对应事情从闲聊变真。
- 陈安把疼用来隐藏记忆问题。
- 赵六看门口，体现白役对权力与风险的敏感。

## 非语言指纹
PASS

陈安：
撑床、扣床沿、扶床柱、扶墙；不长时间示弱。

赵六：
歪靠、伸长胳膊递水、豆子停在半道、收豆、先扫院子。

## 话轮
PASS

不再是机械 FAQ：
- 赵六主动试探“真打懵了？”
- 对处罚问题先拒绝预期问题；
- 陈安不回答“有区别？”的完整理由，转问路线；
- 赵六嘴上结束，身体继续跟。

## 情绪余波
PASS

赵六发现陈安异常后，后续语气由贫嘴 → 警惕 → 劝退 → 撇责 → 跟上。
状态没有每句清零。

## 对话后状态变化
PASS

开始：
赵六只是守着一个刚醒的同屋倒霉蛋。

结束：
赵六意识到陈安真准备查失粮，嘴上否认参与，实际上进入共同动作。

## Local Polish

### DPOL001
原句：
“你今天这脑子，挨完板子以后怎么还比以前费人。”

问题：
“费人”口语意图可懂，但第一次读略需要确认，是“麻烦人 / 折腾人”的意思。

处置：
LOCAL_REWRITE

建议：
“你今天怎么比挨板子以前还难伺候。”

或更符合赵六：
“你今天怎么比昨天那十五板还折腾人。”

第二种略有作者刻意，不建议。

推荐第一种。
