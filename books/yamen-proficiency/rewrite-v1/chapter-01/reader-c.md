# Reader C — 阅读动力

## 最想继续看的问题
不是“谁是真凶”，而是：
陈安现在握着车辙和鞋印，只是一个白役，他接下来怎么把这件事变成周虎愿意核查的事实，同时又不让刘旺立刻把门关死。

## 好奇还是困惑
好奇。

未知项非常明确：
- 刘旺推没推过那袋粮；
- 如果推过，是自己偷还是替别人搬；
- 粮后来去了哪里。

没有因为看不懂而产生的“悬念”。

## 第一章承诺是否成立
- 底层县衙生存：成立。十五板和再次受罚直接推动行动。
- 熟练度：成立。第一次出现建立在真实寻迹后。
- 身份限制：成立但还可在第二章进一步兑现。本章没有让陈安越权审问。
- 家庭 / 债务：只点到为止，符合第一章负荷。

## 结尾
刘旺、车轮、缺角鞋形成具体下一步，继续阅读动力足够。
没有使用“事情才刚开始”等总结句。

## 动力风险
RCM001 / POLISH
系统出现后有一段：
“它没有告诉他谁偷了粮。
也没有告诉他下一步去哪儿。
只是把他刚才确实做过的事，记了下来。”

信息有用，但三句连续解释规则，会让已经建立起来的发现节奏短暂停顿。
建议 Editor 检查是否能压成更少的文字，而不损失系统规则。
