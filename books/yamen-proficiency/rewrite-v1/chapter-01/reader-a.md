# Reader A — 首读理解

## 我理解发生了什么
陈安刚穿越到青溪县衙一个挨过十五板的白役身上。昨天赈粮少了一袋，他和其他当值白役因为说不清责任先挨了板子，如果今天仍没有说法，还可能继续受罚。

他不愿躺着等第二顿板子，于是从杂役房门口的干米开始查看，逐步发现墙边擦痕、木棚铁钉上的蓝麻线、小车辙和缺角鞋印。原主记忆里，失踪的粮袋右下角正是用蓝麻线补过，因此他确认这条移动路线与失粮有关。完成真实寻迹后，系统第一次记录【寻迹·初学 1/100】。

最后，刘旺推着与车辙特征相符的小车回来，左脚鞋后跟也与现场脚印缺角一致。

## 因果链
- 失粮未解决 → 白役可能继续挨罚 → 陈安有现实理由主动查看。
- 门口干米不在正常运粮路线 → 值得往异常方向看。
- 米粒 / 擦痕 / 蓝麻线 / 车辙形成连续移动痕迹。
- 原主记忆确认失粮袋用蓝麻线补过 → 这条路线与失粮建立现实验证。
- 完成一次真实寻迹 → 系统记录技能。
- 刘旺的车和鞋与现场痕迹相符 → 形成下一章需要核查的具体对象。
