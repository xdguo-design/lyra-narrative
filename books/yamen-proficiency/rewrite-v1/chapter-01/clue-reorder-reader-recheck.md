# Chapter 01 Clue Reorder Reader Recheck

视角：第一次阅读的普通读者。
只检查后半章线索推进是否仍像教程关 / 巧合堆叠。

## 1. 米粒
PASS

作用：
只制造“位置异常”。

没有形成连续米粒路线；赵六明确指出后院本来就可能有米。

## 2. 擦痕
PASS

作用：
给一个可能方向。

结果：
到木棚后直接中断，被旧脚印、车轮印、扫帚灰和湿泥淹没。
第一次追踪没有得到奖励性答案。

## 3. 熟练度
PASS

触发点：
第一次实际尝试区分杂乱痕迹之后，且当时“擦痕已经追丢”。

系统出现早于：
- 蓝麻线；
- 旧记忆确认；
- 缺角脚印；
- 刘旺鞋子核对。

因此系统不再等价于“刚才判断正确”。

## 4. 车辙
PASS

只发现一小段一深一浅窄轮印。
它让陈安想到早先正常经过的泔水车，但只能算相似。

刘旺 / 小车已经在找线索之前自然出现，不是被线索召唤。

## 5. 蓝线与记忆
PASS WITH WATCH

蓝线是沿轮印附近立柱主动检查时看到，不再靠“手正好碰到”。

旧记忆由线的粗硬触感触发：
- 只确认昨日搬运批次中有一只蓝线补过的袋子；
- 不能确认它就是最终失踪的一袋。

WATCH：
后续禁止继续用“当前正缺什么信息，原主记忆就精准补什么”的方式推进。

## 6. 脚印
PASS

它是独立待核查项。
发现时刘旺本人没有同步出现。

## 7. 刘旺
PASS

刘旺先作为正常后厨杂役与小车一起进入背景。
最终不是他再次恰好推车回来，而是陈安主动去后厨核对车。

鞋后跟特征在主动核对过程中出现。

## 8. 巧合聚集
明显下降。

旧结构：
连续发现 → 系统 → 认车 → 刘旺准时出现 → 鞋吻合。

新结构：
刘旺 / 车先出现
→ 米粒位置异常
→ 擦痕追丢
→ 系统只记录实际寻迹
→ 短车印
→ 蓝线但不充分
→ 不完整记忆
→ 独立脚印
→ 主动去核对车
→ 才发现鞋特征。

## Remaining Reader Watch
1. 蓝线、脚印仍在同一木棚区域连续出现，但两者都没有独立给出答案，目前可接受。
2. 后续第二章必须通过周虎复核，而不能让陈安一句话把“相似”升级成“就是”。
3. 不能在第二章立刻再给刘旺一个新的决定性巧合证据。

## Verdict
PASS

后半章已从“作者铺好的线索阶梯”调整为“混乱现场中筛出几项需要核查的痕迹”。
