# Chapter 01 Dialogue Rebuild Brief｜陈安 × 赵六

## 场景范围
陈安醒来 → 确认赵六/白役/失粮/十五板 → 决定离开杂役房去看现场。

## 陈安

### 性格
- 先观察、后判断。
- 现实，先算自己会不会继续挨板、丢差事、拖累家里。
- 不喜欢在别人面前显得无能。
- 穿越刚发生，信息不全，但不会把“我什么都不知道”摊出来。

### 面子 / 自我形象
希望赵六把他当成“脑子还清楚、能自己处理的人”。

最怕暴露：
- 自己连昨天发生过什么都记不全；
- 自己疼得连起身都困难；
- 自己只能靠赵六解释。

所以：
- 不直接问“昨天发生了什么”；
- 只问具体事实；
- 疼的时候用动作调整，不解释；
- 不对赵六讲自己的恐惧和家里压力。

### 自我保护
- 先拿最少的问题补足信息；
- 不把真实目的全说出来；
- 不急着说“我要查案”，只说“去看看”；
- 把是否跟来留给赵六自己决定，不求人陪。

### 语言
短、实、少形容。
真正需要信息时会把问题切小。

### 身体
板伤必须一直在。
坐起、下地、穿鞋、走路都会打断他说话。
疼会让他变得更省话，而不是更健谈。

---

## 赵六

### 性格
- 嘴碎、惜命、懂县衙规矩。
- 怕吃亏，第一反应是先撇责任。
- 看起来滑头，但同屋真出事不会彻底撒手。

### 面子 / 自我形象
希望陈安觉得自己：
- 懂门道；
- 不傻；
- 不会再白挨一次板子。

最怕：
- 被陈安带着一起惹事；
- 被当成什么都不知道；
- 明明害怕，却被人看成害怕。

所以：
- 用玩笑包装担心；
- 不直接说“我怕再挨板子”，而是拿板子、班头、规矩来压陈安；
- 嘴上说“不跟”，身体最后还是跟。

### 自我保护
- 先判断陈安是不是被打傻；
- 发现陈安问的问题越来越具体后，开始警觉；
- 提醒“白役看多了也算多事”；
- 跟出去之前先把责任撇干净。

### 语言
先吐槽，再给事实。
严重的事会被他说轻，但真确认危险时话会变少。

### 身体
闲时吃豆。
事情变真时豆子会停、会收起来。
遇风险时先看门口/外面有没有人，再决定说多少。

---

## 两人的关系旧账

### 已冻结事实
- 同为白役。
- 同屋。
- 昨天同批因为失粮挨板。
- 赵六比陈安多混县衙七年。
- 关系尚未发展成真正搭档。

### 当前关系状态
不是朋友式关心，也不是陌生人。

更接近：
“昨天一起倒霉，今天最好谁都别再把谁拖下水。”

### 关系语言
赵六：
- 可以拿陈安挨板开玩笑；
- 可以直接怀疑他被打傻；
- 会提醒风险，但不说“我是为你好”。

陈安：
- 不会对赵六客气解释；
- 会直接问事实；
- 知道赵六怕麻烦，因此不主动请求“陪我去”。

### 本场关系变化
开始：
赵六觉得陈安只是刚醒的同屋倒霉蛋。

结束：
赵六发现陈安今天真的要做点不一样的事。
嘴上拒绝跟，身体却跟上。

这是两人第一次形成最低限度的“共同行动”。

---

## 这场对白必须避免

1. 问一句答一句的 FAQ。
2. 陈安连续盘问。
3. 赵六主动把所有背景解释完整。
4. 两个人同时把真实动机说清楚。
5. 每句后面加看了看/皱眉/沉默。
6. 赵六只靠炒豆体现个性。
7. 陈安只靠冷短句体现个性。
8. 板伤一进入对白就消失。
9. 两个人为了“有性格”强行互损。
10. 把昨天共同挨板扩写成未经冻结的新旧事。

## 本场动作线
赵六：吃豆 → 倒水 → 察觉陈安异常 → 豆子停 → 看门口/压低声音 → 嘴上撇责任 → 收豆跟上。

陈安：醒 → 观察 → 喝水补信息 → 试着坐起受疼 → 继续问最少事实 → 下地 → 不求人陪 → 自己往外走。

## 通过标准
- 去名字测试：大部分对白能识别说话人。
- 换人测试：陈安/赵六台词互换明显失真。
- 两人目标不同。
- 板伤和炒豆只作为身体/行为线，不是标签打卡。
- 对话结束后关系发生实际变化：赵六跟上。

## Narrative Function Contract

### 本场必须完成的读者认知
1. 陈安不是单纯失忆：他的上一段本人记忆来自现代出租屋 / 电脑 / 泡面。
2. 他现在已经身处大梁青溪县，并占据一个同名白役的身体/身份。
3. 昨日西库赈粮少一袋，四个当值白役已各挨十五板。
4. 赵六是同屋、同批挨板的老白役。
5. 陈安决定离开杂役房去看现场；赵六嘴上自保，实际跟上。

### 必须确认的身份 / 关系 / 规则
- 穿越事实必须在本场正文明确落地，不能只存在 Character Card。
- 白役底层身份与再次受罚风险要成立。
- 陈安 / 赵六尚不是成熟搭档，只形成第一次最低限度共同行动。

### 后文依赖接口
- 后文可以使用“原主/这具身体的旧记忆”，因为穿越已确认。
- 出门后第一次看到异常米粒，再询问“正常运粮路线”。
- 房内不得提前完整问完运粮路线，否则会与院内旧段重复。

## Seam Contract

### 前文已经完成
- 两人共同挨板；
- 陈安决定出去看；
- 赵六实际跟上。

### 后文第一次完成
- 观察异常米粒；
- 询问正常运粮路线；
- 发现“米粒位置不在正常路线”这一矛盾；
- 继续追擦痕 / 蓝麻线 / 车辙。

### 禁止重复
- 房内不得问“前院进 / 西库收 / 是否绕后院”的完整路线问题。
- 出门后不得重新上演一次“去不去 / 跟不跟”的同一决定，除非现场出现新风险。
