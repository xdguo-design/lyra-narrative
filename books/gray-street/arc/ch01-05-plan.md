# 《灰街》前五节推进计划

> 第一节《怀表》以已通过最终 Gate 的正文为准。本文件冻结第二至第五节的章节功能，不等于正文会一次性解释全部设定。

## 第二节《遗产》

章节功能：
- 埃文带怀表回事务所，先恢复普通工作节奏，让异常嵌在公务生活里。
- 挂钟继续比正常时间快，芬奇与贝恩的小斗法继续，但不能重复第一节笑点。
- 芬奇正在处理一个码头死者“三个姓氏”的身份问题，用很具体的基层麻烦表现移民身份与登记制度冲突。
- 埃文向贝恩报告托马斯·韦德现场情况。贝恩只给经验性反应，不解释神秘体系。
- 可以出现两则极短的老档案怪事作为“老公务员见过怪东西”的证据，但不能形成神秘物百科。
- 雷蒙德·克莱到访，自称韦德远亲；衣着体面、鞋贵、手上没有劳动茧，真正目标是银怀表。
- 埃文不直接揭穿，通过继承手续和细节问题测试他。克莱在“不必修，那块表走得不准”之类细节上暴露自己事先知道怀表。
- 霍尔送来一张从韦德住处或相关旧物里找到的烧焦纸片：河灯街，第七码头十三号仓。
- 芬奇认出十三号仓早年失火，曾经做进口货仓。
- 章尾：怀表异常加速，表盖内侧在 EVAN GREY / 1 之外形成一句话：“日落以前，归还第一笔。”
- 不解释“第一笔”是什么。

## 第三节《河灯街》

章节功能：
- 埃文先从正常档案和街区关系查“河灯街 / 十三号仓”，不立刻闯仓库。
- 他利用地址登记、旧租约、营业许可、码头装卸记录等基层资料，拼出十三号仓这些年的使用变化。
- 芬奇对旧码头和灰色商人比埃文熟，愿意帮忙的动机必须有自己的利益或人情，不是无条件工具人。
- 霍尔对进入废仓持保留态度；他担心责任、证据链和上级追责。
- 雷蒙德·克莱或其手下在外围施压，但不直接暴露幕后贵族。
- 埃文发现托马斯近期确实去过河灯街，并留下一个与修表生意无关的登记痕迹/票据痕迹。
- 十三号仓已烧毁多年，但附近某个附属库房、看守记录或旧号码仍被人继续使用。
- 怀表对某条“欠账/归还”相关记录出现轻微异常，只表现事实，不解释规则。
- 章尾：埃文确认托马斯最后几天至少两次到过十三号仓附近，而且第二次不是一个人。

## 第四节《十三号仓》

章节功能：
- 埃文、霍尔在有程序依据的前提下进入十三号仓相关区域；芬奇可以参与前段查路/辨人，但不能所有人都跟去。
- 场景强调烧毁后的旧仓与后来偷偷恢复使用的痕迹：门锁、货架、煤灰、近期脚印/搬运痕迹等必须具体。
- 找到与托马斯有关的实物线索：例如修表收据、包装纸、编号、海关无人认领货物的旧批次信息或灰色经纪人留下的中间凭证。
- 线索指向“这块表的价值可能不在表本身，而在来源”，但不能告诉读者终极来源。
- 出现一次现实危险：有人回来取东西/销毁东西/抢走凭证。埃文不能突然变战士，靠空间、霍尔、程序预判或临场选择脱身。
- 不让怀表变成战斗外挂。
- 雷蒙德与这一层灰色网络存在联系，但保持“代理人的代理人”距离。
- 埃文拿到一条能解释“第一笔”可能与托马斯私人账本第一条未结记录有关的线索。
- 章尾：日落越来越近。

## 第五节《日落》

章节功能：
- 埃文必须在日落前处理“第一笔”，但这一节只揭示怀表规则的一小角。
- 他把仓库线索、托马斯私人账本/修表记录、房东与街区登记互相核对，找到第一条长期未结记录对应的人或家庭。
- 这笔“账”不能只是简单还钱；应与托马斯替别人保管、扣留、交换或未归还的一件具体物品/权益有关，体现“归还”比“支付”更重要。
- 埃文依靠公务身份和街区关系完成归还，而不是靠打斗。
- 归还后怀表出现可验证变化：例如数字 1 消退、走速恢复、日期窗变化之一；不要一次解释规则—代价—反噬全貌。
- 埃文意识到托马斯死亡与这块表不是偶然，但仍无法确定托马斯是被谁逼死、自己为什么被选中。
- 雷蒙德一方确认怀表已经认了新持有者，外部压力升级。
- 结尾把故事从“怪表”推进到“有人在追它，而且有人知道它的来源”。
- 不解决国家级阴谋，不引出顶层贵族真名，不让主角力量跳级。

## 前五节共同硬规则

- 正文以完整段落、自然中长句群为主，禁止大量一句一段、电报体、小短句堆节奏。
- 禁止连续裸对白和问卷式一问一答。
- 禁止“不是A而是B”“他不是不怕，只是/而是……”等作者替人物总结心理的模板结构。
- 对白时人物的身体、手上任务、利益、空间和关系必须仍然存在，但不能机械给每句台词补动作。
- 埃文的优势是基层程序、记录、观察和熟悉制度边界，不是全知、神探或战斗天才。
- 芬奇、贝恩、霍尔、哈钦斯太太、雷蒙德都要有自己的利益和选择，不能只递信息。
- 第一卷前段只逐层揭开：怀表异常 → 韦德 → 灰色中间人 → 来源线索；不提前揭顶层。
