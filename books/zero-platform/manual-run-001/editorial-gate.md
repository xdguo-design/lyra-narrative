## First-pass rejection reasons

1. Knowledge leak: 沈砚在正文尚未建立来源时提前知道“47秒”。
2. Rule violation: 原结尾在01:40让无电梯老楼出现“电梯停层声”，等于在00:07窗口之外新增超自然现象。
3. Prompt leakage: “这是一次很清楚的交接”属于连续性提示语，不应出现在小说正文。
4. Exposition overload: 第二、三章一度退化为角色轮流解释设定，叙事动作不足。
5. Device contrivance: 录音内容的出现过于自动化，需要改为角色主动回放/降噪。
6. Character tension: 姜岚隐瞒信息虽存在，但原稿冲突仍偏说明，需要落实到对话选择和行为。

## Gate for following chapters

A chapter must be rewritten before presentation if any of the following occurs:

- established fact is forgotten or reset;
- irreversible resource count increases without a canonical event;
- a character knows something they have not learned;
- a revealed secret is presented as unknown again;
- a relationship/name transition resets;
- a new paranormal rule is introduced only to create a hook;
- exposition replaces scene action for long stretches;
- repeated paragraphs or repeated “first-time” events appear;
- reviewer/instruction/meta language leaks into prose;
- chapter does not materially change situation, relationship, information, cost, or goal.

The reader-facing manuscript is only shown after this gate passes.
