# Character Stress Test Protocol v1

## 目标
验证人物卡不是静态设定，而是能在不同压力、身份与利益结构下生成可辨认但不机械重复的行为。

## 每人至少两轮
Round A：权力 / 证据 / 身份压力
Round B：钱 / 家庭 / 长期关系压力

## 每轮记录格式
CHARACTER_STRESS_V1
【人物】
【场景】
【即时目标】
【最大恐惧】
【手中筹码】
【应出现的第一反应】
【允许让步】
【禁止跨越】
【测试响应】
【失败样本】
【通过标准】
【结果】

## 通过标准
1. 同一人物在两种压力下仍可辨认。
2. 行为可以变化，但变化必须来自身份、筹码、关系和风险变化。
3. 不因为剧情需要突然诚实、勇敢、愚蠢、残忍或温柔。
4. 不把人物卡写成固定口头禅。
5. 至少一个测试必须包含“短期利益 vs 长期关系/信誉”的冲突。
6. 两轮都通过才可判 STABLE。
7. 若跨三类压力仍主动保持人物逻辑，可判 TRANSFERABLE。
