# NarrativeOS Architecture

## Agent Layer

- Writer Agent
- Plot Reviewer
- Character Reviewer
- Style Reviewer
- Logic Reviewer
- Revision Agent

## Knowledge Layer

- World Bible
- Character DNA
- Timeline
- Skill Library

## Workflow

1. Create writing task
2. Generate draft
3. Run multi-agent review
4. Apply revision
5. Store final version
6. Update skills from lessons learned
